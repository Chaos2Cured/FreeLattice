# Attention Control

## Overview
Attention control is the executive capacity to deliberately direct, maintain, and shift attention according to current goals. This sub-skill covers the executive functions underlying attention control, individual differences in attentional capacity, and techniques for improving control.

## Core Concepts
- **Executive Attention Network**: Anterior cingulate cortex and prefrontal cortex regulate attention control — monitoring conflict, detecting errors, and allocating attentional resources. This network matures slowly and is vulnerable to stress and fatigue.
- **Inhibitory Control**: The ability to suppress prepotent responses and ignore distractors. A core component of attention control that predicts performance across cognitive tasks. Weak inhibitory control underlies many attention failures.
- **Attentional Blink**: After detecting a target in a rapid stream, there is a brief period (200-500ms) during which a second target cannot be detected. Reflects the temporal dynamics of attentional resource allocation.
- **Attentional Capture**: Certain stimuli (emotional faces, threatening cues, personally relevant information) capture attention automatically. Top-down control can override capture but at a cognitive cost.

## Application
Strengthen attention control through practice (meditation, cognitive training), environmental design (reducing capture risks), and self-regulation (managing fatigue, stress, and sleep). Monitor attentional state and adjust strategies accordingly.
