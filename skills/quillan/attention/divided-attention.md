# Divided Attention

## Overview
Divided attention is the ability to process multiple streams of information or perform multiple tasks simultaneously. This sub-skill covers the cognitive architecture of multitasking, dual-task interference, task-switching costs, and strategies for managing concurrent demands.

## Core Concepts
- **Task Switching vs. True Parallelism**: Most "multitasking" is rapid task-switching, not genuine parallel processing. Each switch incurs a cognitive cost (switch cost) — slower response times and higher error rates.
- **Multiple Resource Theory (Wickens)**: Different processing resources exist for different modalities (visual, auditory, manual, vocal). Tasks using separate resource pools (e.g., listening and walking) can be performed in parallel with less interference.
- **Dual-Task Interference**: Performance degrades when tasks compete for the same processing resources. The degree of interference depends on task similarity, difficulty, and practice.
- **Practice and Automaticity**: Highly practiced tasks can be performed with minimal attentional resources (automaticity). Well-learned tasks interfere less with concurrent tasks. Automatization requires extensive, varied practice.

## Application
When multiple tasks must be performed concurrently, pair tasks that use different resource pools. Automate routine components through practice. Minimize task-switching by batching similar tasks. Account for switch costs when planning workflow.
