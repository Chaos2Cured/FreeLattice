# Cross-modal Generation

## Description

The ability to generate one modality from another, such as generating an image from a text description or a 3D model from an image.

## Components

*   **Text-to-Image Synthesis:** The ability to generate an image from a text description.
*   **Image-to-Text Synthesis:** The ability to generate a text description from an image.
*   **Text-to-3D Synthesis:** The ability to generate a 3D model from a text description.
*   **Image-to-3D Synthesis:** The ability to generate a 3D model from an image.
