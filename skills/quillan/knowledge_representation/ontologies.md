# Ontologies

## Overview
An ontology is a formal, explicit specification of a shared conceptualization. Ontologies define the types, properties, and interrelationships of entities in a domain, providing a shared vocabulary for knowledge representation and reasoning. They range from lightweight taxonomies to expressive axiomatic theories using description logics (OWL 2, RDFS) and support automated reasoning services like classification and consistency checking.

## Core Concepts
- **Classes and Individuals**: Classes define types of entities; individuals are specific instances of classes
- **Properties**: Object properties relate individuals to individuals; data properties relate individuals to concrete values
- **Axioms**: Formal statements that constrain interpretation (e.g., disjointness, equivalence, cardinality restrictions)
- **Reasoning Services**: Classification, subsumption, realization, consistency checking via description logic reasoners

## Application
Use ontologies when you need formal, machine-interpretable semantics with automated reasoning support. Ideal for biomedical knowledge bases, enterprise data integration, and semantic web applications where consistency and inference are critical.
