# Frame-Based Representation

## Overview
Frame-based representation, introduced by Marvin Minsky, organizes knowledge into structured packages called frames that represent stereotypical situations, objects, or concepts. Each frame contains slots with facets (values, defaults, ranges, procedural attachments). Scripts extend frames to represent stereotypical event sequences. This approach excels at common-sense reasoning, expectation-driven understanding, and story comprehension.

## Core Concepts
- **Frames**: Structured representations with named slots describing attributes and relationships
- **Slots and Facets**: Each slot can have a value, default, range constraint, or attached procedure
- **Scripts**: Predetermined causal chains describing familiar situations (restaurant script, shopping script)
- **Inheritance and Defaults**: Frame hierarchies support property inheritance with default values

## Application
Use frame-based representation for common-sense reasoning, natural language understanding, plan recognition, and story understanding where stereotypical knowledge structures are beneficial.
