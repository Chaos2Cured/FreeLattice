# Source-Target Mapping

## Overview
Source-target mapping is the foundational process of analogical reasoning — identifying systematic correspondences between a well-understood source domain and an unfamiliar target domain. This sub-skill covers the mapping algorithms, constraints, and evaluation criteria used to construct valid analogical mappings.

## Core Concepts
- **Structure-Mapping Theory (Gentner)**: Analogies are about matching relational structures, not surface attributes. The systematicity principle prioritizes mappings that connect deeply interconnected relational systems.
- **Mapping Constraints**: One-to-one mapping (each source element maps to at most one target element), parallel connectivity (relationships must correspond across domains), and candidate inference projection (unmatched source knowledge is projected to the target).
- **Alignment Processes**: Local-to-global alignment (starting with small matches and extending), global constraint satisfaction (finding the maximally consistent global mapping), and incremental mapping (building mappings step by step).
- **Mapping Evaluation**: Structural consistency (how well relational structures align), semantic plausibility (consistency with target domain knowledge), and predictive power.

## Application
When building an analogy, first identify the relational structure of both domains. Construct mappings that prioritize relationships over attributes. Test mappings for systematicity and one-to-one consistency.
