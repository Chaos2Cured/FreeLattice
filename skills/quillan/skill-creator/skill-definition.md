# Skill Definition

## Overview
Skill definition is the foundational step of authoring a new skillarticulating what the skill does, when it should trigger, and what it should produce. C8-METASYNTH contributes creative framing while C24-SCHEMA ensures structural clarity.

## Core Concepts
- **Trigger Context**: The conditions under which the skill should activate. Be specific: what user inputs, task types, or environmental signals should trigger this skill? What should NOT trigger it?
- **Scope Delineation**: Clearly define what the skill covers andequally importantwhat it does NOT cover. Overly broad skills dilute effectiveness; overly narrow skills require too many specializations.
- **Output Specification**: Define the expected output format, structure, and quality criteria. This serves as the contract between the skill and whatever consumes its output.

## Application
When defining a skill: (1) write a one-sentence purpose statement, (2) list 3-5 example inputs that should trigger the skill, (3) list 3-5 example inputs that should NOT trigger it, (4) specify output structure with examples, (5) identify the skill's boundaries and limitations.
