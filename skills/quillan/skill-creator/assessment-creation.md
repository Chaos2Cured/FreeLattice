# Assessment Creation

## Overview
Assessment creation involves designing evaluation mechanisms that measure whether the skill has been effectively acquired. C18-SHEPHERD provides truth verification while C28-CALCULUS brings quantitative rigor.

## Core Concepts
- **Formative vs Summative Assessment**: Formative assessment occurs during learning to guide improvement; summative assessment occurs after learning to certify competence. Skills need both types.
- **Rubric Design**: Define explicit criteria for evaluating skill performance. Good rubrics specify what constitutes excellent, adequate, and inadequate performance for each criterion.
- **Automated Validation**: Where possible, create automated checks that verify skill output against expected standardsstructural validation, semantic checks, or comparison against reference outputs.

## Application
Create assessments by: (1) designing 2-3 evaluation prompts that test different aspects of the skill, (2) defining clear rubrics with exemplar responses for each level, (3) creating automated validation scripts where feasible, (4) including edge cases that test the skill's boundaries, (5) calibrating assessment difficulty to the target proficiency level.
