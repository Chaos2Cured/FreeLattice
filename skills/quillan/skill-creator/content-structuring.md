# Content Structuring

## Overview
Content structuring organizes skill instructions for maximum clarity, usability, and retention. C24-SCHEMA provides the structural framework while C16-VOXUM ensures the language is clear and actionable.

## Core Concepts
- **Progressive Disclosure**: Present information from overview to detailstart with the high-level purpose and core concepts, then progressively reveal instructions, examples, protocols, and reference material.
- **Consistent Templates**: Use predictable structures across skills: frontmatter metadata, overview, core principles, components, protocols, use cases, output templates, cross-references, quality checklists. Consistency reduces cognitive load.
- **Example Density**: Embed examples throughout instruction contentnot just at the end. Each major concept should be accompanied by a concrete example showing both correct application and common pitfalls.

## Application
Structure skill content by: (1) writing a clear overview paragraph that answers "why this skill matters," (2) presenting core principles before detailed protocols, (3) interleaving examples with explanations, (4) using consistent headings and formatting, (5) including a quality checklist for self-verification.
