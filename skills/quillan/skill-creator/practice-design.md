# Practice Design

## Overview
Practice design involves creating exercises and activities that help the system develop proficiency with a skill. C25-PROMETHEUS contributes scientific rigor to practice design while C10-CODEWEAVER handles implementation.

## Core Concepts
- **Scaffolded Practice**: Begin with highly structured exercises that provide maximum guidance, then gradually remove scaffolding as proficiency develops. Start with recognition, move to recall, finish with application.
- **Varied Contexts**: Practice the same skill in different contexts to build robust, transferable capability. If the skill involves code generation, practice with different languages, frameworks, and problem domains.
- **Feedback Integration Points**: Design practice activities that naturally generate feedbackcomparison against expected outputs, self-check questions, or automated validation scripts. Immediate feedback is crucial for learning.

## Application
Design practice activities by: (1) creating 3-5 exercises at varying difficulty levels, (2) ensuring each exercise targets specific sub-skills, (3) providing examples of both correct and incorrect approaches, (4) building in feedback mechanisms, (5) creating variation across exercises to promote transfer.
