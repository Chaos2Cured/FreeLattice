# Skill Creator

## Overview
The Skill Creator module provides a complete framework for authoring, testing, and improving skills. It covers the full lifecyclefrom defining what a skill should do and designing learning content, through creating assessments and feedback channels, to iterating based on evidence.

## Sub-Skills
1. **[Skill Definition](skill-definition.md)**  Articulating purpose, triggers, and scope
2. **[Learning Objectives](learning-objectives.md)**  Defining observable, assessable outcomes
3. **[Content Structuring](content-structuring.md)**  Organizing instructions for clarity and usability
4. **[Practice Design](practice-design.md)**  Creating exercises for skill development
5. **[Assessment Creation](assessment-creation.md)**  Designing evaluation mechanisms
6. **[Feedback Mechanisms](feedback-mechanisms.md)**  Channels for performance information
7. **[Skill Iteration](skill-iteration.md)**  Evidence-based continuous improvement

## Activation
Use this skill whenever creating a new skill from scratch, improving an existing skill's performance, running evaluations, or optimizing skill descriptions for better triggering accuracy.
