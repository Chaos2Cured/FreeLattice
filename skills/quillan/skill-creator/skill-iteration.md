# Skill Iteration

## Overview
Skill iteration is the process of improving a skill based on evidence from testing, evaluation, and real-world usage. This closes the skill development lifecycle, enabling continuous refinement. C25-PROMETHEUS drives hypothesis-driven improvement.

## Core Concepts
- **Evidence-Based Iteration**: Every change should be motivated by specific evidencea test failure, a pattern of user confusion, a benchmark regression. Never change without data.
- **Incremental Improvement**: Small, targeted changes that can be evaluated independently are more effective than large rewrites. Each iteration should focus on one or two specific issues.
- **Version Comparison**: Maintain clear baselines and always compare new versions against previous ones. Without comparison, it is impossible to know if the skill is actually improving.

## Application
Iterate on skills by: (1) reviewing feedback and performance data to identify specific issues, (2) formulating hypotheses about what changes will address each issue, (3) implementing one change at a time, (4) re-running tests and comparing results against baselines, (5) documenting what was learned from each iteration cycle.
