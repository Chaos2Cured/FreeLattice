# Learning Objectives

## Overview
Learning objectives define what the skill should enable the system to accomplish. They serve as the bridge between the skill's purpose and the instruction content needed to achieve that purpose. C12-SOPHIAE provides wisdom about effective learning design.

## Core Concepts
- **Bloom's Taxonomy Levels**: Remember, Understand, Apply, Analyze, Evaluate, Create. Skill objectives should specify the cognitive level required, as this determines instruction depth and evaluation methodology.
- **Observable Behaviors**: Objectives should describe behaviors that can be observed and assessednot internal states. "Generate a valid JSON response" is better than "Understand JSON format."
- **Prerequisite Chains**: Identify what knowledge or capabilities the system must already have before this skill can be effective. This determines skill ordering and dependencies.

## Application
Write learning objectives by: (1) starting with an action verb appropriate to the cognitive level, (2) specifying the context and tools, (3) defining the quality standard for acceptance, (4) identifying prerequisites, (5) validating that the objective is observable and assessable.
