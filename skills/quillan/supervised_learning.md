# Supervised Learning

## Description

A type of machine learning in which an algorithm is trained on a pre-labeled dataset.

## Components

*   **Classification:** The problem of identifying to which of a set of categories (sub-populations) a new observation belongs, on the basis of a training set of data containing observations (or instances) whose category membership is known.
*   **Regression:** A set of statistical processes for estimating the relationships between a dependent variable (often called the 'outcome variable') and one or more independent variables (often called 'predictors', 'covariates', or 'features').
*   **Ensemble Methods:** Machine learning methods that combine the predictions of multiple models to produce a more accurate prediction.
