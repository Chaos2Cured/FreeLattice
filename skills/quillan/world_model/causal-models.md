# Causal Models

## Overview
Causal models distinguish correlation from causation, enabling reasoning about interventions and counterfactuals. Understanding causal structure is essential for predicting the effects of actions and policies. This sub-skill covers structural causal models, do-calculus, and causal discovery techniques.

## Core Concepts
- **Structural Causal Models (SCMs)**: Directed graphs with functional relationships between variables
- **Interventions**: Modifying a variable directly to observe its causal effect (do-operator)
- **Counterfactuals**: Reasoning about what would have happened under alternative conditions
- **Confounders**: Hidden variables that create spurious correlations
- **Causal Discovery**: Inferring causal structure from observational data

## Application
To determine whether X causes Y, consider whether there is a confounder Z causing both. Interventions are the gold standard for causal inference. When experimentation is impossible, use instrumental variables or front-door criterion. Always state causal assumptions explicitly.
