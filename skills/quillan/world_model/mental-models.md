# Mental Models

## Overview
Mental models are cognitive frameworks that help us understand how things work by providing simplified representations of complex systems. They shape how we perceive problems, make decisions, and predict outcomes. This sub-skill covers building, maintaining, and applying mental models across diverse domains.

## Core Concepts
- **Model Structure**: Core components, relationships, and boundaries of the model
- **Abstraction Level**: Choosing the right detail for the decision at hand
- **Model Limitations**: Understanding what the model captures and what it omits
- **Multiple Models**: Using complementary models for different aspects of the same system
- **Model Testing**: Comparing model predictions against observations to validate structure

## Application
Explicitly state the assumptions underlying any mental model. No model is complete; the question is whether it is useful for the specific decision. Use multiple models in parallel to gain different perspectives on the same situation.
