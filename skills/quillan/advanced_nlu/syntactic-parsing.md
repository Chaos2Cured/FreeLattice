# Syntactic Parsing

## Overview
Syntactic parsing analyzes the grammatical structure of sentences, identifying how words group into phrases and how those phrases relate hierarchically. Constituency parsing builds tree structures using context-free grammars; dependency parsing represents grammatical relations between individual words. Parsing is the foundation for semantic interpretation, information extraction, and many NLU tasks.

## Core Concepts
- **Constituency Parsing**: Building phrase structure trees (NP, VP, PP) using CFG rules
- **Dependency Parsing**: Identifying head-dependent relations (subject, object, modifier)
- **Ambiguity Resolution**: Handling attachment ambiguity, coordination scope, and PP attachment
- **Transition-Based and Graph-Based Methods**: Efficient parsing algorithms for real-time applications

## Application
Use syntactic parsing for grammar checking, relation extraction, question answering, machine translation preprocessing, and any NLU task requiring structural sentence analysis.
