# Named Entity Recognition

## Overview
Named Entity Recognition (NER) identifies and classifies named entities in text into predefined categories such as persons, organizations, locations, dates, monetary values, and more. NER is a fundamental information extraction task that enables knowledge base population, entity linking, relation extraction, and semantic search.

## Core Concepts
- **Entity Types**: Person, organization, location, date, time, money, percent, product, event
- **Sequence Labeling**: BIO/IOB tagging schemes for marking entity boundaries
- **NER Approaches**: Rule-based (gazetteers, patterns), feature-based (CRF), neural (BiLSTM-CRF, Transformer)
- **Entity Linking**: Connecting recognized entities to knowledge base entries (Wikidata, DBpedia)

## Application
Use NER for information extraction, knowledge graph construction, document indexing, content categorization, and any task requiring identification of specific entities in text.
