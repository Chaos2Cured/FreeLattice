# Discourse Analysis

## Overview
Discourse analysis studies language beyond the sentence level, examining how sentences combine into coherent texts and conversations. It covers discourse structure (segmentation, relations), coherence relations (causal, temporal, elaborative), discourse connectives, topic structure, and genre-specific conventions. Discourse analysis bridges local sentence meaning and global text interpretation.

## Core Concepts
- **Rhetorical Structure Theory**: Nuclearity relations (Elaboration, Cause, Contrast) between discourse units
- **Discourse Connectives**: Words and phrases that signal discourse relations (however, therefore, moreover)
- **Topic Structure**: Topic introduction, maintenance, shift, and drift in discourse
- **Genre Analysis**: Conventions of narrative, argumentative, expository, instructional discourse

## Application
Use discourse analysis for text summarization, dialogue systems, essay scoring, argument mining, and any task requiring understanding of text-level organization and coherence.
