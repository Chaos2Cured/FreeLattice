# Pragmatic Inference

## Overview
Pragmatic inference uncovers meaning beyond literal semantic content, drawing on context, speaker intent, and conversational principles. This covers Gricean implicature (what is implied but not stated), presupposition (background assumptions), speech act recognition (request, promise, threat), and deixis (context-dependent reference). Pragmatic inference is essential for understanding indirect, figurative, and culturally embedded language.

## Core Concepts
- **Conversational Implicature**: Flouting Grice's maxims to convey additional meaning
- **Presupposition Triggers**: Definite descriptions, factive verbs, aspectual verbs, change-of-state verbs
- **Speech Act Classification**: Assertive, directive, commissive, expressive, declarative acts
- **Context and Common Ground**: Modeling shared knowledge and beliefs between interlocutors

## Application
Use pragmatic inference for truly deep language understanding, detecting indirect requests, interpreting sarcasm and humor, cross-cultural communication, and any context where literal meaning is insufficient.
