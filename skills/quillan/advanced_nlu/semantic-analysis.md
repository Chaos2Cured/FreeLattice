# Semantic Analysis

## Overview
Semantic analysis determines the meaning of linguistic expressions, from word senses to sentence-level meaning composition. This covers lexical semantics (word meanings and relations), compositional semantics (how word meanings combine), semantic role labeling (who did what to whom), and formal semantic representations (logical forms, meaning representations).

## Core Concepts
- **Lexical Semantics**: Word senses, semantic relations (synonymy, antonymy, hyponymy), polysemy
- **Compositional Semantics**: Lambda calculus, function application, quantifier scope
- **Semantic Role Labeling**: Identifying agent, patient, instrument, location, and other thematic roles
- **Formal Representations**: Discourse Representation Theory, Abstract Meaning Representation

## Application
Use semantic analysis for deep language understanding, question answering, information extraction, text entailment, and any task requiring meaning beyond surface form.
