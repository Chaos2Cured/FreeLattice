# Source Evaluation
## Overview
Source evaluation is the critical assessment of information sources for authority, accuracy, currency, and relevance. This sub-skill covers frameworks for evaluating credibility, detecting misinformation, and assessing source bias.
## Core Concepts
- **CRAAP Test**: Currency, Relevance, Authority, Accuracy, Purpose as criteria for source evaluation
- **Primary vs Secondary Sources**: Distinguishing original research from derivative accounts
- **Bias Detection**: Identifying perspective, agenda, and selective presentation in sources
- **Fact-Checking**: Verifying claims against multiple independent reliable sources
## Application
Apply source evaluation when conducting research, evaluating news and media, assessing information quality, or building trusted knowledge bases.
