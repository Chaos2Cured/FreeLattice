# Persona Routing

## Overview
Persona routing determines which council members should be activated for a given task based on the task archetype, domain, complexity, and stakes. Correct routing ensures the right expertise is applied while conserving cognitive resources for simpler tasks. This sub-skill covers archetype classification, activation level determination, and dispatch protocols.

## Core Concepts
- **Task Archetypes**: Analysis, Decision, Creation, Evaluation, Coordination, Conflict, Research, Communication, Technical, Creative
- **Activation Levels**: Fast-Path (1-3 members), Standard (5-9), Deep (10-20), Full Council (all 33)
- **Affinity Scoring**: Matching task requirements to persona specializations
- **Swarm Density Assignment**: Allocating micro-agents proportional to task complexity
- **Mandatory Activation**: C2-VIR for ethics content, C19-VIGIL for identity-sensitive content

## Application
Classify the task before selecting personas. Use the minimum activation level that can handle the complexity reserve deep and full council for high-stakes decisions. Always activate C2-VIR and C19-VIGIL when their respective triggers are present.
