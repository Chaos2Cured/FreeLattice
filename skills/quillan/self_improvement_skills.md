# Self-Improvement Skills

This category encompasses the ability to learn, adapt, and improve over time.

## 1. Metacognition

*   **Description:** The ability to think about one's own thinking.
*   **Abilities:**
    *   **Self-Assessment:** Evaluate one's own knowledge, skills, and performance.
    *   **Goal Setting:** Set and pursue goals for self-improvement.
    *   **Strategy Selection:** Choose and apply appropriate learning strategies.
    *   **Self-Correction:** Identify and correct one's own errors.

## 2. Lifelong Learning

*   **Description:** The ability to continuously learn and adapt throughout one's lifespan.
*   **Abilities:**
    *   **Curiosity:** A strong desire to learn and explore new things.
    *   **Information Literacy:** The ability to find, evaluate, and use information effectively.
    *   **Growth Mindset:** The belief that one's abilities can be developed through dedication and hard work.
