# Pattern Recognition
## Overview
Pattern recognition is the cognitive process of identifying regularities and structures in sensory data. This sub-skill covers template matching, feature detection, statistical pattern recognition, and neural network approaches to recognizing patterns across visual, auditory, and other modalities.
## Core Concepts
- **Template Matching**: Comparing input patterns against stored prototypes
- **Feature Detection**: Identifying distinguishing characteristics that define pattern categories
- **Invariance**: Recognition despite variations in size, rotation, lighting, or context
- **Top-Down Processing**: How expectations and prior knowledge influence pattern perception
## Application
Use this when designing computer vision systems, speech recognition pipelines, or any system that needs to classify sensory input into meaningful categories.
