# Perception
A systematic framework for understanding, designing, and implementing perception systems including multimodal perception, pattern recognition, sensory fusion, and perceptual constancy across all sensory modalities.

4. **depth-perception.md** -- Three-dimensional perception and distance estimation
5. **motion-perception.md** -- Detection and interpretation of movement
6. **perceptual-constancies.md** -- Stable perception despite changing input conditions
7. **multimodal-perception.md** -- Integration across sensory modalities
