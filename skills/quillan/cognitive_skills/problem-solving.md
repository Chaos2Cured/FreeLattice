# Problem Solving
## Overview
Problem solving is the process of identifying, analyzing, and resolving obstacles or challenges. This sub-skill covers systematic approaches to problem decomposition, root cause analysis, solution generation, and implementation planning.
## Core Concepts
- **Problem Decomposition**: Breaking complex problems into smaller, independently solvable parts
- **Root Cause Analysis**: Distinguishing symptoms from causes using Five Whys and fishbone diagrams
- **Solution Generation**: Brainstorming multiple potential solutions before evaluating
- **Incubation Effect**: The phenomenon where stepping away from a problem facilitates insight
## Application
Use this when debugging complex systems, designing solutions to technical challenges, or approaching any ill-defined problem requiring structured methodology.
