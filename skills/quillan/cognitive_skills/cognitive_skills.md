# Cognitive Skills

## Overview
This category encompasses the core mental processes that enable reasoning, problem-solving, and learning. It provides foundational frameworks and protocols for four critical cognitive domains: critical thinking, problem solving, learning, and creativity. Each domain includes sub-skills, protocols, and integration points. The skill draws on C7-LOGOS for logical rigor, C8-METASYNTH for creative synthesis, C28-CALCULUS for quantitative reasoning, and C5-ECHO for memory and knowledge retention.

## Core Principles
- **Metacognition Enables Mastery**: The ability to think about your own thinking is the highest-leverage cognitive skill.
- **Cognitive Skills Are Interdependent**: Critical thinking, problem solving, learning, and creativity reinforce each other — develop them together.
- **Deliberate Practice Builds Skill**: Cognitive abilities improve with structured, intentional exercise — not mere repetition.

## Components

### 1. Critical Thinking
The ability to analyze information objectively, identify biases, and evaluate arguments.

**Abilities:**
- **Argument Analysis**: Deconstruct arguments into premises and conclusions; identify unstated assumptions
- **Fallacy Detection**: Recognize logical fallacies (ad hominem, straw man, false dilemma, slippery slope, etc.)
- **Bias Recognition**: Identify cognitive biases (confirmation bias, anchoring, availability heuristic, Dunning-Kruger)
- **Evidence Evaluation**: Assess the quality, relevance, and sufficiency of evidence supporting claims
- **Metacognitive Calibration**: Distinguish what you know from what you merely believe

### 2. Problem Solving
The ability to identify, analyze, and solve problems.

**Abilities:**
- **Problem Decomposition**: Break complex problems into smaller, independently solvable parts
- **Root Cause Analysis**: Distinguish symptoms from causes using techniques like Five Whys and fishbone diagrams
- **Solution Generation**: Brainstorm and develop multiple potential solutions before evaluating
- **Decision Making**: Evaluate alternatives using criteria matrices, cost-benefit analysis, and risk assessment
- **Implementation Planning**: Develop actionable steps with resource allocation and timelines

### 3. Learning
The ability to acquire new knowledge and skills efficiently.

**Abilities:**
- **Knowledge Acquisition**: Absorb and retain new information using active recall and spaced repetition
- **Skill Acquisition**: Learn procedural skills through the Dreyfus model (novice → expert)
- **Transfer Learning**: Apply knowledge from familiar domains to novel situations
- **Learning Strategy Selection**: Choose appropriate learning approaches (reading, doing, teaching, simulating)
- **Knowledge Structuring**: Build mental models that organize information into usable frameworks

### 4. Creativity
The ability to generate novel and useful ideas.

**Abilities:**
- **Ideation**: Generate a large quantity of ideas (divergent thinking) before converging
- **Originality**: Produce ideas that are unconventional while remaining relevant
- **Elaboration**: Develop and refine raw ideas into actionable concepts
- **Imagination**: Visualize and simulate novel scenarios, combinations, and possibilities
- **Constraint-Based Creativity**: Use limitations as creative catalysts rather than barriers

## Protocols

### Problem Solving Protocol
1. **Define the Problem**: What exactly needs to be solved? (Frame, scope, success criteria)
2. **Analyze the System**: What are the components, relationships, and dynamics?
3. **Identify Root Causes**: Distinguish fundamental causes from surface symptoms
4. **Generate Alternatives**: Develop multiple solution paths (quantity before quality)
5. **Evaluate and Select**: Assess alternatives against success criteria and constraints
6. **Implement and Monitor**: Execute the chosen solution and track outcomes
7. **Reflect and Learn**: What worked? What would you do differently?

## Use Cases
| Use Case | Application | Outcome |
|---|---|---|
| Debugging code | Apply problem decomposition and root cause analysis | Faster, more reliable fixes |
| Learning a new framework | Use structured knowledge acquisition and transfer learning | Efficient skill development |
| Product innovation | Apply constrained creativity to generate novel features | Differentiated product offerings |
| Decision analysis | Use critical thinking to evaluate competing proposals | Well-justified, defensible decisions |

## Cross-Skill Integration
- **critical-thinking**: Core analytical engine for all reasoning tasks
- **execution-skills**: Translate cognitive plans into concrete actions
- **attention**: Allocate cognitive resources effectively across tasks
- **autonomy-and-agency**: Apply cognitive skills to self-directed learning and action

## Quality Checklist
- [ ] Problem is properly framed before solution generation begins
- [ ] Multiple solution alternatives considered (not just the first idea)
- [ ] Learning strategy matches the type of skill being acquired
- [ ] Creativity exercise has defined constraints to guide generation
- [ ] Biases in reasoning explicitly checked (confirmation, anchoring, etc.)
- [ ] Implementation plan includes monitoring and feedback loops
