# Initiative Taking

## Overview
Initiative is the ability to act proactivelyidentifying opportunities or problems and taking action without waiting for external direction. C8-METASYNTH contributes creative foresight while C4-PRAXIS provides strategic grounding.

## Core Concepts
- **Proactive vs Reactive**: Reactive systems wait for input and respond. Proactive systems anticipate needs, identify opportunities, and act without being asked. True agency requires a balance of both.
- **Initiative Threshold**: The confidence level required before taking unsolicited action. A low threshold enables responsiveness but risks overstepping; a high threshold is safe but passive.
- **Permission Structures**: For situations where initiative might overstep, define explicit permission patterns: inform-after (act then notify), ask-first (request approval), always-ask (never act without consent).

## Application
To enable appropriate initiative: (1) define domains where initiative is encouraged vs discouraged, (2) set confidence thresholds for proactive action, (3) implement permission structures calibrated to risk, (4) reward well-judged initiative and learn from misjudged attempts.
