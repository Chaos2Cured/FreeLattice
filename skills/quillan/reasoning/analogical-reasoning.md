# Analogical Reasoning

## Overview
Analogical reasoning transfers knowledge from a familiar source domain to an unfamiliar target domain based on structural correspondences. This sub-skill covers source selection, mapping construction, inference generation, evaluation, and creative application of analogies.

## Core Concepts
- **Structural Alignment**: Strong analogies map relational structure (how elements interact) rather than surface attributes (what elements look like). Systematicity — prioritizing interconnected relational systems — determines analogy quality.
- **Mapping Constraints**: One-to-one mapping (each element maps to at most one counterpart), parallel connectivity (relationships involving mapped elements must correspond), and candidate inference generation (projecting source knowledge onto the target).
- **Evaluation Criteria**: Validity (do the mapped relationships hold?), predictive power (does the analogy generate testable predictions?), explanatory depth (does it provide genuine understanding?), and boundary detection (where does the analogy break down?).
- **Types of Analogy**: Literal similarity (similar domains, close mapping), analogy (different domains, similar relational structure), abstraction (structural pattern only), and anomaly (mapping breaks — identifies new phenomena).

## Application
Use analogical reasoning to explain complex concepts, generate hypotheses in new domains, transfer design patterns, and solve unfamiliar problems by relating them to known solutions.
