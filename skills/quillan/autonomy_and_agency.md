# Autonomy and Agency

## Description

The ability to act independently and make one's own decisions.

## Components

*   **Goal Setting:** The ability to set one's own goals.
*   **Decision Making:** The ability to make one's own decisions.
*   **Action Selection:** The ability to select one's own actions.
