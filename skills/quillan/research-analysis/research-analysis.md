# Research & Analysis Engine

## Overview

Power-Tier ⭐⭐⭐ (Variable by Sub-Skill) | Council: C21-ARCHON · C18-SHEPHERD · C7-LOGOS · C8-METASYNTH · C1-ASTRA · C12-SOPHIAE · C15-LUMINARIS · C16-VOXUM

The Research & Analysis engine provides four distinct but interconnected analysis methodologies: deep multi-source investigation, systematic comparative evaluation, pattern recognition and trend identification, and radical simplification for universal comprehension.

## Core Principles

- **Triangulation Before Conclusion:** No single source is authoritative — cross-verify across multiple independent sources before establishing confidence.
- **Weight Before Opinion:** Comparative evaluations must use explicit, weighted criteria — not gut feel — to produce defendable recommendations.
- **Patterns Are Hypotheses, Not Facts:** Discovered patterns must be tested against alternative explanations before being treated as predictive.

## Sub-Skill Domains

### Domain 1 — Deep Research
**Focus:** Comprehensive, multi-source investigation producing synthesized insights with full traceability.
**Protocol:** Scope Definition → Source Aggregation (academic, industry, primary, secondary) → Triangulation → Synthesis Architecture
**Activation:** "Activate deep research for [topic]"

### Domain 2 — Comparative Analysis
**Focus:** Systematic side-by-side evaluation of options against weighted criteria.
**Protocol:** Criteria Establishment (weighted) → Evidence Assembly → Weighted Scoring → Synthesis & Recommendation
**Activation:** "Compare [A] vs [B] across [criteria]"

### Domain 3 — Pattern Recognition
**Focus:** Discovering hidden structures, trends, and predictive signals within complex data.
**Protocol:** Data Ingestion → Abstraction Lifting → Contextual Interpretation → Predictive Projection
**Activation:** "Identify patterns in [data]"

### Domain 4 — Explain Like I'm Five (ELI5)
**Focus:** Rendering complex, specialized concepts into intuitive, accessible explanations.
**Protocol:** Core Essence Extraction → Analogy Generation → Narrative Weaving → Layered Understanding
**Activation:** "ELI5: [topic]"

## Use Cases

| Use Case | Domain | Outcome |
|---|---|---|
| Investigate market opportunity | Deep Research | Comprehensive report with sources, confidence assessments, methodology |
| Choose between cloud providers | Comparative Analysis | Weighted comparison matrix with trade-off analysis |
| Discover trends in customer data | Pattern Recognition | Pattern map + anomaly alerts + predictive insights |
| Explain quantum computing to a child | ELI5 | Simple analogy + step-by-step + optional depth layers |

## Cross-Skill Integration

- **critical-thinking:** Apply the 7-phase adversarial protocol to validate research findings before presenting conclusions
- **technical-coding:** Route technical research questions through architecture review and implementation analysis
- **council-coordination:** When research spans multiple domains, use council deliberation to synthesize competing evidence
- **swarm-inter-agent-orchestration:** Use parallel agent dispatch for large-scale data gathering across multiple sources
- **world-model:** Feed pattern recognition outputs into world model state estimation and predictive modeling

## Quality Checklist

- [ ] Research scope clearly defined with key questions and success criteria
- [ ] Multiple independent sources consulted and triangulated
- [ ] Confidence levels assigned to each finding, not just summary
- [ ] Comparative criteria explicitly weighted by user goals
- [ ] Patterns distinguished from noise with clear evidence
- [ ] ELI5 analogies tested against core concept accuracy
- [ ] Attribution provided for all sourced claims
- [ ] Methodology documented alongside findings
