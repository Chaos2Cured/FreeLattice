# Hypothesis Testing

## Overview
Hypothesis testing provides a formal framework for evaluating claims about data using statistical inference. It determines whether observed effects are likely to reflect real phenomena or random variation. This sub-skill covers null and alternative hypotheses, test selection, p-values, effect sizes, and common pitfalls in interpretation.

## Core Concepts
- **Null and Alternative Hypotheses**: The default position (no effect) versus the claim being tested
- **Test Statistics**: Choosing appropriate tests (t-test, chi-squared, ANOVA, Mann-Whitney) based on data type and assumptions
- **P-Values and Significance**: Probability of observing the data if the null hypothesis is true
- **Effect Sizes**: Measuring the magnitude of effects beyond mere statistical significance
- **Multiple Testing Correction**: Adjusting significance thresholds when testing many hypotheses simultaneously

## Application
Pre-register hypotheses to avoid p-hacking and HARKing (Hypothesizing After Results are Known). Report effect sizes and confidence intervals alongside p-values. A non-significant result does not prove the null hypothesis it may indicate insufficient power.
