# Motor Control

## Overview
The Motor Control module provides a comprehensive framework for commanding physical movementfrom low-level proprioception and feedback control to high-level movement planning and motor learning. Designed for roboticists, simulation engineers, and anyone building systems that move.

## Sub-Skills
1. **[Movement Planning](movement-planning.md)**  Transforming task goals into motion sequences
2. **[Coordination Patterns](coordination-patterns.md)**  Multi-joint coordination and synergy
3. **[Fine Motor Skills](fine-motor-skills.md)**  Precise, small-scale movements
4. **[Gross Motor Skills](gross-motor-skills.md)**  Large-scale locomotion and whole-body motion
5. **[Feedback Control](feedback-control.md)**  Closed-loop state correction
6. **[Motor Learning](motor-learning.md)**  Improving movement through practice
7. **[Proprioception](proprioception.md)**  Sensing the body's own state in space

## Activation
Load this skill for any motor control taskrobot arm control, mobile robot locomotion, game character animation, or physical simulation of moving systems.
