# Logical Proofs

## Overview
Logical proofs are formal demonstrations that a conclusion follows from premises using permissible inference rules. This sub-skill covers proof construction techniques, proof strategies, and common proof patterns across propositional and predicate logic.

## Core Concepts
- **Direct Proof**: Assume the premises are true, apply inference rules step by step, derive the conclusion. Each step must be justified by a rule or a previously established result.
- **Proof by Contradiction (Reductio)**: Assume the negation of the desired conclusion, derive a contradiction with the premises, thereby establishing that the original conclusion must be true.
- **Proof by Cases**: If a premise is a disjunction (A or B), prove the conclusion in each case separately. Useful when dealing with exhaustive possibilities.
- **Mathematical Induction**: Prove a base case holds, then prove that if the statement holds for an arbitrary case k, it holds for k+1. Essential for reasoning about recursive structures and sequences.

## Application
Construct formal proofs when absolute logical certainty is required — in mathematical reasoning, system specifications, and formal verification. Use proof strategies to structure complex chains of reasoning.
