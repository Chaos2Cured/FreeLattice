# Logical Reasoning

Systematic process of using rational steps based on valid premises to reach sound conclusions. Covers formal logic systems, argument analysis protocols, fallacy detection, proof techniques, and the practical integration of logic with uncertainty and real-world constraints.

## Sub-Skills
1. Formal Logic — Mathematical frameworks for valid inference
2. Argument Analysis — Systematic examination of argument structure and strength
3. Fallacy Detection — Identification and analysis of reasoning errors
4. Premise-Conclusion Mapping — Visual and structural representation of arguments
5. Logical Proofs — Formal demonstration techniques and proof strategies
6. Critical Questioning — Systematic interrogation of claims and reasoning
7. Reasoning Biases — Cognitive distortions and debiasing strategies
