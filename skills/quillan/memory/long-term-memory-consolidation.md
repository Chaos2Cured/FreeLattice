# Long-Term Memory Consolidation

## Overview
Consolidation is the process by which labile short-term memories are stabilized into durable long-term representations. This sub-skill covers synaptic consolidation (minutes to hours), systems consolidation (days to years), sleep-dependent memory processing, and reconsolidation. Understanding consolidation informs study schedules, sleep hygiene, and memory rehabilitation.

## Core Concepts
- **Synaptic Consolidation**: Immediate stabilization via protein synthesis and structural changes at synapses. Occurs within minutes to hours of encoding and is vulnerable to disruption during this window.
- **Systems Consolidation**: Gradual reorganization of memory traces from hippocampus-dependent to cortex-dependent storage. The standard model posits that the hippocampus acts as a rapid-indexing system that eventually transfers to distributed cortical networks.
- **Sleep and Memory**: Slow-wave sleep facilitates declarative memory consolidation; REM sleep facilitates procedural and emotional memory processing. Sleep spindles and sharp-wave ripples coordinate hippocampal-neocortical dialogue.
- **Reconsolidation**: Retrieved memories become labile again and must be re-stabilized. This provides a window for memory updating — old memories can be modified when reactivated.

## Application
Schedule learning sessions with sleep intervals between them. Allow for consolidation windows after intense learning. Use retrieval practice to trigger reconsolidation and strengthen memory traces. Avoid interference during consolidation periods.
