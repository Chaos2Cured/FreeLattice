# Working Memory Management

## Overview
Working memory is the limited-capacity system that temporarily holds and manipulates information during cognitive tasks. This sub-skill covers strategies for managing working memory load, optimizing capacity utilization, and reducing cognitive interference. Effective working memory management is critical for complex reasoning, problem-solving, and learning.

## Core Concepts
- **Baddeley's Model**: Central executive coordinates attention and task management; phonological loop handles verbal information; visuospatial sketchpad manages visual/spatial data; episodic buffer integrates information with long-term memory.
- **Cognitive Load Theory**: Intrinsic load (task complexity), extraneous load (distracting presentation), and germane load (productive schema construction) must be balanced within working memory capacity limits.
- **Chunking**: Grouping individual items into meaningful units expands effective capacity. Expertise in a domain enables larger, more sophisticated chunks.
- **Rehearsal Strategies**: Maintenance rehearsal (rote repetition) maintains items temporarily; elaborative rehearsal (meaningful processing) transfers information to long-term memory.

## Application
Reduce extraneous cognitive load by simplifying task presentations. Use chunking to group related information. Offload working memory demands to external tools (notes, diagrams, code comments). Alternate between focused processing and consolidation breaks.
