# Forgetting Curve Strategies

## Overview
The forgetting curve, first described by Hermann Ebbinghaus, describes the exponential decay of memory retention over time without active maintenance. This sub-skill covers strategies for counteracting forgetting — including spaced repetition algorithms, retrieval scheduling, and interference management — enabling durable long-term retention.

## Core Concepts
- **Ebbinghaus Forgetting Curve**: Retention declines rapidly within the first hours and days after learning, then levels off. The rate of forgetting depends on encoding strength, prior knowledge, and material meaningfulness.
- **Spaced Repetition Systems**: Scheduling review sessions at increasing intervals dramatically reduces forgetting. Algorithms include Leitner system (physical flashcard boxes), SM-2 (SuperMemo's interval calculation), and FSRS (Free Spaced Repetition Scheduler with adaptive parameters).
- **Interference Effects**: Proactive interference (old memories disrupt new learning) and retroactive interference (new learning disrupts old memories) accelerate forgetting. Managing interference patterns improves retention.
- **Retrieval Practice Effect**: Each successful retrieval attempt strengthens the memory trace and resets the forgetting curve. The degree of strengthening depends on retrieval difficulty (desirable difficulties).

## Application
Implement a spaced repetition system with adaptive intervals based on performance. Schedule reviews to occur just before the forgetting curve would make retrieval fail. Monitor retention rates and adjust parameters (initial interval, ease factor, interval modifier) for optimal performance.
