# Retrieval Techniques

## Overview
Retrieval is the process of accessing stored information from memory. This sub-skill covers the various mechanisms and strategies for effective recall — from free recall and cued recall to recognition, spaced retrieval, and the testing effect. Understanding retrieval mechanisms is essential for designing memory systems and learning protocols.

## Core Concepts
- **The Testing Effect**: Active retrieval practice produces stronger long-term retention than passive restudy. Each retrieval attempt strengthens the memory trace and creates additional retrieval pathways.
- **Retrieval Cues**: Context-dependent, state-dependent, and semantic cues enhance recall by providing associative pathways to target memories. The encoding specificity principle states that retrieval cues are most effective when encoded alongside the target information.
- **Spaced Retrieval**: Retrieval practice distributed across time — expanding intervals, equal intervals, or adaptive scheduling — produces superior retention compared to massed practice.
- **Recognition vs. Recall**: Recognition (identifying previously encountered information) is generally easier than recall (generating information without cues), but recall produces stronger memory strengthening.

## Application
Design retrieval practice schedules using spaced repetition algorithms (Leitner, SM-2, FSRS). Match retrieval format to the desired use case — cued recall for factual knowledge, free recall for conceptual understanding, and recognition for familiarity-based tasks.
