# Encoding Strategies

## Overview
Memory encoding is the process of transforming sensory input into a format that can be stored and later retrieved. This sub-skill covers the full spectrum of encoding techniques — from mnemonic devices to elaborative encoding, dual-coding theory, and the levels-of-processing framework. Effective encoding determines the durability and retrievability of memory traces.

## Core Concepts
- **Levels of Processing (Craik & Lockhart)**: Deeper semantic processing produces more durable memories than shallow perceptual processing. Elaboration, distinctiveness, and self-reference enhance depth.
- **Dual-Coding Theory (Paivio)**: Information encoded through both verbal and visual channels is remembered better than information encoded through a single channel.
- **Mnemonic Devices**: Method of loci, pegword system, keyword method, chunking, and acronyms — structured techniques for encoding arbitrary information into memorable formats.
- **Elaborative Encoding**: Linking new information to existing knowledge structures — the more connections formed, the stronger the memory trace.

## Application
Apply encoding strategies by first identifying the nature of the material to be remembered (facts, procedures, concepts, experiences). Match the encoding strategy to the material type and retrieval requirements. Use elaborative encoding for conceptual learning, mnemonics for arbitrary lists, and dual-coding for abstract concepts.
