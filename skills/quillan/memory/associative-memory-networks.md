# Associative Memory Networks

## Overview
Associative memory is the ability to learn and recall relationships between items, forming the foundation of semantic networks, knowledge graphs, and content-addressable memory. This sub-skill covers how associations are formed, strengthened, and retrieved — both in biological neural networks and artificial systems.

## Core Concepts
- **Hebbian Learning**: "Neurons that fire together, wire together." Associations are strengthened by synchronous activation. The computational analogue is the outer product update in Hopfield networks and attention mechanisms in Transformers.
- **Spreading Activation**: Activating one concept automatically activates associated concepts along network pathways. The strength and distance of activation decay with each step, enabling context-sensitive retrieval.
- **Pattern Completion**: Given a partial cue, the full associated pattern is retrieved. This is the basis of content-addressable memory — recall by content rather than by address.
- **Computational Models**: Hopfield networks (energy-based attractors), Boltzmann machines (probabilistic completion), self-attention (Transformer), and associative memory in RNNs implement associative principles in AI systems.

## Application
Design knowledge representations that exploit associative structure — build rich semantic networks with meaningful connections. Use spreading activation principles for context-sensitive retrieval. Implement pattern completion for robust recall from partial or noisy cues.
