# Belief Attribution

## Overview
Belief attribution is the ability to infer what others believe about the world, including true beliefs (matching reality), false beliefs (differing from reality), and beliefs about beliefs (recursive). It requires modeling another's epistemic accesswhat they have perceived, been told, or can inferand reasoning about how they would update their beliefs given that evidence.

## Core Concepts
- **True Belief Attribution**: Inferring beliefs that accurately reflect reality based on shared evidence
- **False Belief Understanding**: Recognizing that someone can hold a belief that contradicts reality
- **Epistemic Access Modeling**: Tracking what information another agent has had access to
- **Belief Update Reasoning**: Modeling how new evidence would (or would not) change an agent's beliefs

## Application
Use belief attribution for cooperative AI, educational systems (modeling learner misconceptions), negotiation agents, deception detection, and any system that must reason about what others know.
