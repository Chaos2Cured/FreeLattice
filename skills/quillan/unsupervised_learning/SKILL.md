# Unsupervised Learning
A comprehensive skill for applying unsupervised learning methods including clustering, dimensionality reduction, association rule learning, and anomaly detection. Essential for discovering hidden patterns in unlabeled data.

4. **density-estimation.md** -- Modeling the probability distribution of data
5. **association-rules.md** -- Discovering relationships between variables
6. **manifold-learning.md** -- Non-linear dimensionality reduction preserving geometry
7. **generative-models.md** -- Learning distributions to generate new samples
