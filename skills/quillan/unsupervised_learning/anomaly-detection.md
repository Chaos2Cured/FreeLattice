# Anomaly Detection
## Overview
Anomaly detection identifies rare items, events, or observations that differ significantly from the majority of data. This sub-skill covers statistical methods, proximity-based approaches, isolation-based methods, and reconstruction-based techniques.
## Core Concepts
- **Isolation Forest**: Anomaly detection by isolating observations through random feature partitioning
- **Local Outlier Factor**: Measuring local density deviation to identify outliers
- **One-Class SVM**: Learning a boundary around normal data points to identify novelties
- **Reconstruction Error**: Using autoencoders to detect anomalies through poor reconstruction
## Application
Use anomaly detection for fraud detection, network intrusion detection, system health monitoring, quality control, and identifying unusual patterns.
