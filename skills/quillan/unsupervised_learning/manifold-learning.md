# Manifold Learning
## Overview
Manifold learning assumes high-dimensional data lies on or near a lower-dimensional manifold. This sub-skill covers non-linear dimensionality reduction techniques that preserve the intrinsic geometry of data.
## Core Concepts
- **Manifold Hypothesis**: Real-world high-dimensional data concentrates near a lower-dimensional manifold
- **Isomap**: Preserving geodesic distances between points using neighborhood graphs
- **Locally Linear Embedding**: Preserving local linear relationships between neighboring points
- **Spectral Embedding**: Using eigenvalue decomposition of similarity matrices for dimensional reduction
## Application
Apply manifold learning for non-linear dimensionality reduction, data visualization, feature extraction, and understanding data geometry.
