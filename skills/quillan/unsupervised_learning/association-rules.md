# Association Rules
## Overview
Association rule learning discovers interesting relationships between variables in large databases. This sub-skill covers frequent itemset mining, rule generation, evaluation metrics, and algorithms including Apriori, FP-Growth, and Eclat.
## Core Concepts
- **Support**: The frequency with which an itemset appears in the dataset
- **Confidence**: The conditional probability that the consequent occurs given the antecedent
- **Lift**: The ratio of observed confidence to expected confidence under independence
- **Apriori Principle**: Any subset of a frequent itemset must also be frequent
## Application
Use association rules for market basket analysis, recommendation systems, cross-selling pattern discovery, and co-occurrence pattern detection.
