# Density Estimation
## Overview
Density estimation constructs an estimate of the probability density function underlying observed data. This sub-skill covers parametric and non-parametric approaches including kernel density estimation, Gaussian mixture models, and normalizing flows.
## Core Concepts
- **Kernel Density Estimation**: Non-parametric method estimating density by placing kernels on each data point
- **Gaussian Mixture Models**: Probabilistic model representing density as a weighted sum of Gaussian components
- **Bandwidth Selection**: Choosing the smoothing parameter that controls the bias-variance tradeoff in KDE
- **Normalizing Flows**: Transforming a simple base distribution through invertible mappings to model complex densities
## Application
Apply density estimation for generative modeling, outlier scoring, statistical inference, data imputation, and understanding data distribution characteristics.
