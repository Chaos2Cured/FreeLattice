# Learning Objectives
## Overview
Learning objectives are clear, measurable statements that describe what learners should know or be able to do after instruction. This sub-skill covers objective formulation using taxonomies, alignment with assessment, and best practices for communicating expectations.
## Core Concepts
- **Bloom Taxonomy**: Hierarchical classification of cognitive skills from remember through create
- **SMART Objectives**: Specific, Measurable, Achievable, Relevant, and Time-bound learning goals
- **Performance Verbs**: Action verbs that describe observable and measurable learner behaviors
- **Objective-Assessment Alignment**: Ensuring assessments directly measure stated learning objectives
## Application
Apply learning objective frameworks when designing courses, writing lesson plans, developing assessments, or communicating expectations to learners.
