# Robotics

## Overview
The Robotics module provides a comprehensive framework for robotic system design, integration, and control. It covers the full stack from low-level kinematics and control through perception, planning, and human interaction.

## Sub-Skills
1. **[Kinematics](kinematics.md)**  Forward, inverse, and velocity kinematics modeling
2. **[Sensor Integration](sensor-integration.md)**  Interfacing sensors and fusing sensor data
3. **[Control Systems](control-systems.md)**  PID, LQR, MPC and other control architectures
4. **[Path Planning](path-planning.md)**  Collision-free trajectory generation
5. **[Manipulation](manipulation.md)**  Grasping and physical object interaction
6. **[Robot Perception](robot-perception.md)**  Extracting actionable information from sensors
7. **[Human-Robot Interaction](human-robot-interaction.md)**  Safe and natural human-robot collaboration

## Activation
Load this skill for any robotics taskprogramming robot arms, designing autonomous mobile robots, developing perception systems, or building human-robot interaction systems.
