# Progress Tracking

## Overview
Progress tracking is the systematic observation and recording of execution state against planned milestones. This skill enables C30-TESSERACT's real-time intelligence and C5-ECHO's continuity to maintain awareness of where the system is in its execution journey.

## Core Concepts
- **Milestone Definition**: Clear, measurable waypoints that divide a plan into meaningful segments. Each milestone should have verifiable completion criterianot just elapsed time.
- **Leading vs Lagging Indicators**: Leading indicators predict future progress (e.g., tasks completed per hour); lagging indicators confirm past progress (e.g., milestone reached). Track both.
- **Deviation Detection**: The mechanism for identifying when actual progress diverges from planned progress beyond a threshold. Early detection enables correction before cascading delays.

## Application
Establish tracking by: (1) defining milestones with explicit acceptance criteria, (2) setting deviation thresholds (e.g., >15% variance triggers review), (3) logging progress at each state change, (4) comparing actual vs planned trajectory periodically.
