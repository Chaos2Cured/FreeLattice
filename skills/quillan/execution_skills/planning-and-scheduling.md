# Planning and Scheduling

## Overview
Planning and scheduling transform goals into time-bound sequences of concrete actions. This skill draws on C4-PRAXIS's strategic decomposition and C14-KAIDO's efficiency optimization to create feasible, resource-aware execution plans.

## Core Concepts
- **Decomposition Tree**: Breaking a goal into sub-goals, then into tasks, then into atomic actions. Each decomposition step should expose clear dependencies and resource requirements.
- **Dependency Mapping**: Identifying which tasks must precede others (hard dependencies) versus those that can run in parallel (soft dependencies). Critical path analysis for bottleneck identification.
- **Time-Boxing vs Event-Driven**: Fixed-schedule planning (tasks at specific times) versus trigger-based execution (task starts when conditions are met). Choose based on predictability of the environment.

## Application
For any multi-step goal: (1) decompose into sub-tasks, (2) identify dependencies, (3) estimate effort per task, (4) sequence with critical path analysis, (5) include buffer for uncertainty.
