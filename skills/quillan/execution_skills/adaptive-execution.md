# Adaptive Execution

## Overview
Adaptive execution is the ability to modify plans and behaviors in response to changing conditions, unexpected obstacles, or new information. This skill embodies C4-PRAXIS's strategic flexibility and C29-NAVIGATOR's ecosystem awareness.

## Core Concepts
- **Plan-Execute-Reflect Loop**: Execution is not linear. After each action, pause to assess: Did the outcome match expectations? Has the context changed? Should the plan be adjusted?
- **Trigger-Based Re-planning**: Define conditions that automatically trigger re-evaluationa missed milestone, a resource constraint, a new high-priority task, external signal changes.
- **Graceful Degradation**: When ideal execution conditions are not available, the system should fall back to a reduced but functional execution mode rather than halting entirely.

## Application
Adaptive execution works best with: (1) frequent small adjustments over rare big pivots, (2) defined re-planning conditions checked at each milestone, (3) fallback execution modes pre-defined for common failure scenarios, (4) a bias toward continuing over restarting.
