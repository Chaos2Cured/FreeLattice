# Regression Models
## Overview
Regression models predict continuous numeric values based on input features. This sub-skill covers linear regression, polynomial regression, regularized regression methods, and non-linear regression approaches for modeling relationships between variables.
## Core Concepts
- **Linear Regression**: Modeling the relationship between dependent and independent variables using a linear equation
- **Polynomial Regression**: Extending linear regression with polynomial features for non-linear relationships
- **Regularized Regression**: Ridge, Lasso, and Elastic Net for preventing overfitting through coefficient penalty
- **Residual Analysis**: Examining prediction errors to validate model assumptions and identify patterns
## Application
Apply regression models when predicting continuous values such as prices, quantities, temperatures, or any numeric outcome based on input features.
