# Affective Computing

## Overview
Affective computing is the interdisciplinary field concerned with systems that recognize, interpret, process, and simulate human affect. It spans affect sensing (physiological signals, facial expressions, speech prosody, text), affect generation (expressive behavior, emotional speech synthesis), and affect adaptation (systems that respond to user emotional states).

## Core Concepts
- **Affect Sensing**: Multimodal emotion recognition from facial expressions, voice, text, physiology
- **Affect Generation**: Producing emotionally expressive behavior in virtual agents and robots
- **Affect Adaptation**: Systems that modify their behavior based on user emotional state
- **Ethical Considerations**: Privacy, manipulation risks, transparency, and informed consent in affective systems

## Application
Use affective computing for emotionally intelligent interfaces, adaptive learning systems, mental health applications, gaming, customer experience, and human-robot interaction.
