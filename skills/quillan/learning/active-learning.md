# Active Learning
## Overview
Active learning is an instructional approach where learners actively engage with material through discussion, problem-solving, and reflection rather than passively receiving information. This sub-skill covers strategies for active engagement, the theoretical basis in cognitive science, and implementation techniques.
## Core Concepts
- **Retrieval Practice**: Actively recalling information from memory strengthens long-term retention
- **Elaboration**: Connecting new information to existing knowledge through explanation and examples
- **Interleaving**: Mixing different topics during study to improve discrimination and transfer
- **Generation Effect**: Information is better remembered when learners generate it themselves
## Application
Apply active learning strategies when designing training programs, studying new subjects, or building educational software that promotes engagement.
