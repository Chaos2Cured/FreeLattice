# Experiential Learning
## Overview
Experiential learning is learning through direct experience and reflection on doing. This sub-skill covers Kolb learning cycle, the role of concrete experience in knowledge construction, and methods for integrating hands-on learning into education.
## Core Concepts
- **Kolb Learning Cycle**: Concrete experience leads to reflective observation, abstract conceptualization, and active experimentation
- **Learning Styles**: Individual preferences for how one engages with the experiential learning cycle
- **Reflective Practice**: Systematic reflection on experience to derive lessons and insights
- **Authentic Learning**: Learning situated in realistic contexts that mirror real-world application
## Application
Apply experiential learning when designing internships, laboratory courses, project-based learning, or any educational context where hands-on experience is valuable.
