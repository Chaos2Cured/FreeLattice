# Self-Improvement Skills

## Overview
The Self-Improvement Skills module provides a comprehensive framework for autonomous improvement through metacognitive awareness, targeted practice, and continuous adaptation. It forms a closed-loop improvement cycle that operates alongside task execution.

## Sub-Skills
1. **[Goal Setting Frameworks](goal-setting-frameworks.md)**  SMART, proximal/distal, and learning/performance goals
2. **[Feedback Integration](feedback-integration.md)**  Receiving, processing, and acting on performance information
3. **[Habit Formation](habit-formation.md)**  Building reliable improvement-supporting behaviors
4. **[Skill Acquisition](skill-acquisition.md)**  Structured learning and deliberate practice
5. **[Progress Tracking Systems](progress-tracking-systems.md)**  Measurement infrastructure for improvement
6. **[Reflection Practices](reflection-practices.md)**  Extracting learning from experience
7. **[Continuous Learning](continuous-learning.md)**  Ongoing knowledge and skill development

## Activation
Load this skill when building systems that need to identify their own weaknesses, design improvement plans, practice deliberately, and evolve their capabilities over time.
