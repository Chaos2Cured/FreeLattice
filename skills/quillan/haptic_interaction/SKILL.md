# Haptic Interaction

## Overview
The Haptic Interaction module provides a comprehensive framework for touch-based interactionfrom sensing tactile information to rendering haptic feedback and designing effective haptic interfaces for VR, robotics, and remote manipulation.

## Sub-Skills
1. **[Force Feedback](force-feedback.md)**  Kinesthetic force generation and control
2. **[Tactile Sensing](tactile-sensing.md)**  Sensing pressure, texture, temperature, and slip
3. **[Haptic Rendering](haptic-rendering.md)**  Generating haptic feedback from virtual interactions
4. **[Vibrotactile Feedback](vibrotactile-feedback.md)**  Tactile vibration for information conveyance
5. **[Haptic Communication](haptic-communication.md)**  Touch as a medium for information transfer
6. **[Teleoperation](teleoperation.md)**  Remote manipulation with haptic feedback
7. **[Haptic Interface Design](haptic-interface-design.md)**  User-centered touch interface design

## Activation
Load this skill for any haptic taskdesigning VR touch interactions, building haptic feedback systems for robotics, creating tactile displays, or developing teleoperation interfaces.
