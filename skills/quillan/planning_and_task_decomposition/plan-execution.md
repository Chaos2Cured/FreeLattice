# Plan Execution

## Overview
Plan execution transforms planned actions into real-world outcomes, monitoring progress, adapting to changes, and learning from outcomes. Even the best plan degrades without disciplined execution and adaptive management. This sub-skill covers execution monitoring, adaptive control, and post-hoc analysis for continuous improvement.

## Core Concepts
- **Execution Monitoring**: Tracking progress against plan with key performance indicators
- **Variance Analysis**: Detecting deviations between planned and actual progress
- **Adaptive Control**: Adjusting plans in response to deviations while preserving goals
- **Decision Gates**: Checkpoints where go/no-go decisions are made based on current status
- **Retrospective Analysis**: Post-execution review to capture lessons for future planning

## Application
Monitor leading indicators, not just lagging ones. When deviations occur, first assess whether the goal is still achievable before adjusting the plan. Document execution outcomes systematically to improve future planning estimates and assumptions.
