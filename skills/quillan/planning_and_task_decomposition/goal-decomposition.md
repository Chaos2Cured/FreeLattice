# Goal Decomposition

## Overview
Goal decomposition breaks high-level objectives into smaller, manageable sub-goals that can be tackled independently. It transforms abstract aspirations into concrete, actionable milestones with clear success criteria. This sub-skill covers hierarchical decomposition, means-ends analysis, and constraint-based refinement techniques.

## Core Concepts
- **Hierarchical Breakdown**: Decomposing top-level goals into progressively finer sub-goals
- **Success Criteria**: Defining measurable indicators that a goal has been achieved
- **Means-Ends Analysis**: Comparing current state to goal state and identifying gaps
- **Constraint Propagation**: How constraints at higher levels constrain lower-level options
- **Goal Conflict Resolution**: Handling cases where sub-goals pull in different directions

## Application
Start with a clear statement of the top-level goal and its success criteria. Decompose into 3-7 major sub-goals, each with its own success criteria. Continue decomposing until each leaf task is independently executable. Validate that completing all sub-goals achieves the parent goal.
