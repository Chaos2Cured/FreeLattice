# Resource Planning

## Overview
Resource planning allocates limited assets (people, time, budget, equipment, information) across competing tasks to achieve goals efficiently. It ensures that plans are feasible given real-world constraints and identifies resource bottlenecks before they cause failures. This sub-skill covers capacity planning, leveling, and allocation optimization.

## Core Concepts
- **Resource Identification**: Cataloging available resources with capacities and capabilities
- **Capacity Planning**: Matching resource supply to task demand over time
- **Resource Leveling**: Smoothing demand to avoid peaks and troughs in resource usage
- **Allocation Algorithms**: Assignment methods from simple greedy to constraint-based optimization
- **Resource Contention**: Managing situations where multiple tasks need the same resource simultaneously

## Application
Explicitly model resource constraints alongside task dependencies. Use resource leveling after initial scheduling to identify feasibility issues. For knowledge work, consider that people are not interchangeable; skill matching matters as much as availability.
