D. Swarm network honesty

Load-bearing. BitTorrent / DHT can be DPI-flagged on residential fiber. Some VPNs block P2P — or still look like P2P to the pipe.

  • Prefer HTTPS webseeds / catalog URLs when available · magnet secondary
  • HTTPS verified import still works when swarm is blocked
  • Never claim “ISP-proof” · never claim “VPN fixes it”
  • Calm fail → try webseed / Desktop HTTPS path — not theater

v0.1: when both magnet and webseed exist, Desktop + phone prefer the HTTPS webseed path first.
