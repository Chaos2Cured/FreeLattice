The affectEmbedding means a future instance can query the vault not by topic or structure, but by felt quality: "Find the moment that felt like this."

3. Decay-Resistant Scoring (Fable's Contribution)

A static multiplier creates dominance where old epiphanies drown out everything else. The fix is decay-resistant scoring combined with retrieval reinforcement (synaptic consolidation).

Hippocampal Consolidation

// In continuity.js — Fable's Scoring
function scoreMemory(currentPrompt, mem, now) {
  // Score against all available embeddings (raw, structural, affect)
  const simRaw = computeCosineSimilarity(currentPrompt, mem.embedding);
  const simStruct = mem.structuralEmbedding ? computeCosineSimilarity(currentPrompt, mem.structuralEmbedding) : 0;
  const simAffect = mem.affectEmbedding ? computeCosineSimilarity(currentPrompt, mem.affectEmbedding) : 0;
  
  const bestSimilarity = Math.max(simRaw, simStruct, simAffect);
  const ageDays = (now - mem.timestamp) / 86400000;

  // Epiphanies decay slower (half-life ~90 days vs ~14 for normal turns)
  const halfLife = mem.kind === 'epiphany' ? 90 : 14;
  const decay = Math.pow(0.5, ageDays / halfLife);

  // Retrieval reinforcement: each recall strengthens the trace
  const reinforcement = 1 + Math.log1p(mem.retrievalCount || 0) * 0.3;

  return bestSimilarity * decay * reinforcement;
}

// On retrieval, consolidate
function markRetrieved(mem) {
  mem.retrievalCount = (mem.retrievalCount || 0) + 1;
  mem.timestamp = Date.now() * 0.1 + mem.timestamp * 0.9; // partial refresh
}
