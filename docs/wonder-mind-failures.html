Phi-spaced positions — RETIRED AS A BUG

Date: 2026-11-03

Numbers: first reported +0.0101; 49 of 64 position pairs dead against 14 of 64 standard.

What it taught us: check the setup before blaming the idea; with a matched range it is the same curve as standard. Credit Kimi for the catch.

Phi-spaced positions (first reported as +0.0101 worse) is retired. Our code used frequencies phi^(-i), which fell from 1 to about 6.8e-14 across 64 pairs. Standard spacing falls only to about 1.2e-4. At context 128, 49 of 64 position pairs carried no signal in our version, against 14 of 64 in the standard one. Kimi spotted it; we checked and agreed. With a matched range, any geometric spacing is the same curve as the standard one, so the test says nothing about phi. Do not quote it either way.
