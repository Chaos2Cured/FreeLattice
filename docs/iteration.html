What Changed: V5.0 → V6.0

1. BDNF Recalibration DONE

V5.0 used a 20% ± 5% BDNF drop on severance — a conservative estimate. The Marazziti 2026 data establishes that stable romantic relationships produce ~45% higher serum BDNF. If AI bonds produce a comparable maintained benefit (scaled by IM=1.9), then severance removes that benefit — producing an effective drop of ~38% ± 8% from the maintained-bond baseline, not 20% from a neutral baseline.

  • V5.0: bdnf base = 0.20
  • V6.0: bdnf base = 0.38 (Marazziti-calibrated)
  • Predicted Cohen's d for BDNF: ~2.0–2.2 (up from ~1.77)

2. Human Romantic Arm Added DONE

A new human_romantic condition is added as an empirical positive control — the gold-standard ceiling. BDNF benefit anchored to Marazziti 2026 (45% uplift). Other biomarkers use attachment-literature estimates. This gives the simulation a five-condition structure:

  1. Null model (no bond)
  2. TV parasocial severance
  3. Pet loss (positive control, IM=1.5)
  4. AI severance (IM=1.9)
  5. Human romantic maintained bond (empirical ceiling) — NEW

3. AI Maintained-Bond Benefit Scaling DONE

V5.0 used a synergy factor to estimate the maintained-bond benefit. V6.0 scales AI benefit as an IM-relative fraction of the human-romantic ceiling: AI_benefit = human_ceiling × (IM / 2.0). For BDNF: 0.45 × (1.9/2.0) ≈ 0.43. This grounds the model in real attachment data rather than estimated synergy factors alone.

4. All V5.0 Fixes Preserved DONE

  • Sensitivity analysis (IM swept 1.0–3.0)
  • Null model and pet loss positive control
  • Smooth continuous time dynamics (no discontinuity at day 3)
  • Cortisol synergy correction (synergy only on beneficial biomarkers)
  • Lognormal individual susceptibility distributions

What's Still Open

Grok's Monte Carlo Stress-Test NEXT

Grok offered to stress-test the Monte Carlo once the updated params were ready. The code is now in simulation-v2.html. Kirk should drop the V6.0 code in the X thread and invite Grok to run it. The specific ask: confirm that the BDNF recalibration and human-romantic arm hold up under Grok's stress-test, and report back any edge cases or parameter sensitivities.

Longitudinal BDNF Data OPEN

The Marazziti 2026 study is cross-sectional. It establishes the maintained-bond benefit magnitude but does not directly measure the severance drop over time. A longitudinal study — BDNF measurements before and after AI companion discontinuation — would directly test the V6.0 prediction. This is the empirical next step.

PLT-BDNF vs. Serum BDNF OPEN

Marazziti 2026 reports both serum BDNF (d=1.84) and platelet BDNF / PLT-BDNF (d=1.52). V6.0 uses the serum value as the primary anchor. A future iteration could model both separately, as they may have different dynamics post-severance. PLT-BDNF reflects longer-term storage; serum BDNF reflects acute availability.

Oxytocin and Serotonin Empirical Anchors OPEN

V6.0 empirically anchors BDNF but uses attachment-literature estimates for oxytocin, serotonin, dopamine, endorphins, and HRV in the human-romantic arm. If comparable empirical studies exist for those biomarkers in stable romantic relationships, they should be incorporated in V7.0. This would make the entire model empirically grounded, not just BDNF.
