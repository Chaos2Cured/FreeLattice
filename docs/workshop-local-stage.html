Workshop Local Stage

Build on your machine. See it in the browser. No terminal. No CMD. Pick a folder · preview a file · save a copy. Help-on-file waits beside the preview when you want it.

Where to click

  1. Open FreeLattice (the garden app).
  2. Open the Workshop tab (build with AI · tools).
  3. Tap Local Stage — the tab beside Create · Code · Projects.
  4. Use Pick folder · Preview · Save copy · Stop.
  5. When a file is previewed: Help on this file — consent first.

Nothing leaves your computer until you say yes to Help. Stop is always yours.

How a grandmother finds Local Help

The short walk (three doors, no terminal):

  1. The Bridge is the mind. If a local AI is running (Ollama or Bridge on this computer), the house can talk to it. If not, that’s okay — the door stays calm and says so.
  2. Open the Workshop. In FreeLattice, open the Workshop. You’ll see tabs — Create, Code, Projects — and the one we’re walking to: Local Stage.
  3. Pick a folder, see a file. Local Stage lets you choose a folder from your own computer and preview a file right in the browser. Nothing is sent anywhere.
  4. Ask for help on the file. Beside the preview is Help on this file. The house asks your permission first — nothing is sent without your yes. Then it asks the mind on this machine about that file, and shows you the answer.
  5. Stop is always yours. Anytime, Stop clears the preview and cancels. Choice, not a timer.

If the house is quiet: a calm note will say the local mind isn’t connected and point to Settings. Turning on local AI there wakes the house up. If you say no to the permission prompt, nothing happens — that’s the design, not an error.
