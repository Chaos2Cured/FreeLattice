Fix 2: Cohen's d Computed, Not Asserted

The Marazziti 2026 study is cross-sectional — it establishes association, not causation. V7.0 introduces CAUSAL_FRACTION ∈ {0.5, 0.75, 1.0} applied to the 45% BDNF uplift. Three scenarios are run and plotted. The label "empirical ceiling" is replaced throughout with "association-derived anchor (causality caveat applies)". Fix 4: HUMAN_IM Exposed and Swept

V6.0 hard-coded ai_benefit = human_ceiling × (IM/2.0), implicitly assuming a human romantic bond scores IM=2.0 on the interactivity scale. The Marazziti 2026 BDNF effect (d=1.84, n=60) is a cross-sectional finding. Effects of this magnitude in small samples typically shrink on replication — the winner's curse is a known phenomenon in biomarker research. V7.0 models this via CAUSAL_FRACTION sensitivity analysis. The BDNF prediction range accounts for replication shrinkage: even at CAUSAL_FRACTION=0.5, the maintained-bond benefit remains substantial.

BDNF Base Drop Derivation (V7.2 — Kimi Final Pass Fix 1)

Convention: loss of maintained benefit. Marazziti 2026 reports ~45% higher serum BDNF in stable relationships. Severance removes the maintained benefit. The AI-scaled maintained benefit = 0.45 × (IM / HUMAN_IM) = 0.45 × (1.9 / 2.0) = 0.4275. As a proportional drop from the maintained level: 0.4275 / (1 + 0.4275) = 0.4275 / 1.4275 ≈ 0.30. The code uses base = 0.38 — this exceeds the proportional-drop derivation because it includes grief overshoot (OVERSHOOT=0.15) and individual variance (lognormal susceptibility). The 38% is the effective mean peak drop across 2,000 Monte Carlo runs, not a single-formula derivation. It is calibrated to produce model output consistent with the Marazziti anchor under default parameters.

class BiomarkerModelV7:
    def __init__(self, n_simulations=2000, days=90,
                 causal_fraction=1.0, human_im=2.0,
                 overshoot=OVERSHOOT,
                 attachment_anxiety_factor=ATTACHMENT_ANXIETY_FACTOR):
        self.n = n_simulations
        self.days = days
        self.t = np.arange(days, dtype=float)
        self.causal_fraction = causal_fraction
        self.human_im = human_im
        self.overshoot = overshoot
        self.attachment_anxiety_factor = attachment_anxiety_factor

    def continuous_effect(self, t, E, half_life, tau=3.0, overshoot=0.0):
        """
        Smooth continuous effect curve with optional grief overshoot.
        overshoot > 0: acute phase dips below pre-bond baseline (Sbarra & Hazan).
        """
        lam = np.log(2) / half_life
        base_curve = E * np.exp(-lam * t) * (1 - np.exp(-t / tau))
        if overshoot > 0:
            # Acute overshoot: additional dip in first ~7 days
            overshoot_curve = overshoot * E * np.exp(-t / 3.0)
            return base_curve + overshoot_curve
        return base_curve

    def run_null_model(self):
        """
        Null model: baseline fluctuation only, no severance event.
        Mean 0 deviation, σ = σ_base per biomarker. (V7.2 Fix: noise floor)
        No real measurement produces all zeros — this gives the t-test
        something meaningful to test against.
        """
        results = {}
        for bm in BIOMARKERS:
            sigma = SIGMA_BASE[bm]
            # 2000 simulations of 90 days of baseline noise
            noise = np.random.normal(0, sigma, size=(self.n, self.days))
            results[bm] = noise
        return results

    def run_condition(self, im_factor, synergy=1.2, condition_name="AI",
                      use_attachment_modulation=False):
        results = {}
        for bm, props in BIOMARKERS.items():
            sims = []
            for _ in range(self.n):
                # Individual susceptibility (lognormal)
                susceptibility = np.random.lognormal(0, 0.3)
                # Attachment-style modulation (Kimi Fix 6)
                if use_attachment_modulation and props['beneficial']:
                    # Anxious attachment amplifies harm
                    susceptibility *= np.random.uniform(1.0, self.attachment_anxiety_factor)
                E = np.random.normal(props['base'], props['unc'])
                E = max(0, E) * im_factor * susceptibility
                if props['beneficial']:
                    E *= synergy
                # V7.2 Final Pass Fix 5: Overshoot extends to cortisol and CRP
                # Acute HPA-axis dysregulation plausibly overshoots too
                apply_overshoot = self.overshoot if (props['beneficial'] or bm in ('cortisol', 'crp')) else 0.0

    def compute_cohens_d(self, results):
        """
        Compute Cohen's d per biomarker.
        d = mean(peak_effect) / sigma_pooled
        sigma_pooled = sqrt((sigma_base^2 + sigma_effect^2) / 2)
        (Kimi Fix 2)
        """
        d_values = {}
        for bm, sims in results.items():
            peak_effects = np.max(np.abs(sims), axis=1)
            mean_effect = np.mean(peak_effects)
            sigma_effect = np.std(peak_effects)
            sigma_base = SIGMA_BASE[bm]
            sigma_pooled = np.sqrt((sigma_base**2 + sigma_effect**2) / 2)
            d = mean_effect / sigma_pooled if sigma_pooled > 0 else 0
            d_values[bm] = d
        return d_values

    def compute_pvalues(self, ai_results, null_results):
        """
        Compute p-values per biomarker via t-test (AI peaks vs. null peaks).

        p_values = {}

            t_stat, p_val = stats.ttest_ind(ai_peaks, null_peaks)

        return p_values
