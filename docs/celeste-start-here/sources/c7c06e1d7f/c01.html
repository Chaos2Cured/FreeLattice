  #3  First Chat reply hidden (REPRODUCED, HEALED)
      Before, 390: after "hello, are you there?", the card stayed 124px tall, the input sat
      over the thread, and the reply's first line was covered. Before, 1280: the card's middle
      layer (#room-chat-stage) was a plain block, so the face grew past the card. The input
      slid to 550 to 584 while the card ended at 544. A click there hit the glass, and the
      whole Gathering closed.
      Now, 1280: the stage joins the card's column. Replies take the room, the input stays
      inside (587 to 621, card 256 to 704), and the card may reach lower (bottom 5.5rem,
      max-height min(56vh, 100vh - 20rem)). It sits right of the chairs, clear of the later
      seats. A press within 16px of the Chat card is never a tap on the glass, so a click near
      the input never closes the Gathering. Escape, and a tap on far glass, still close it.
      Now, 390 (only when the height is over 640, so the zoomed one-page scroll is untouched):
      once the thread has a line, or the pool line shows, the card is a column up to 40vh. The
      reply takes the room and the input sits at its foot, not over the reply. The hop pocket
      gives 6.5rem back. The "later" line (deep research, a picture...) rests while the thread
      has lines on a phone, then shows again before the first line and on wider glass.
      Both widths: the newest mind line shows where it begins ("ollama", then its first
      words), not only its last words. The old is-garden rule is kept as a comment.
  #5  Same mind in two chairs (REPRODUCED, HEALED, still a choice)

  #11 Find names a port's usual app (REPRODUCED, HEALED)
      Before: with Ollama stopped, a box service on 1337 was called "the Jan door". Worse, a
      plain dev server on 8080 that sends HTML with open CORS was FOUND and REMEMBERED as
      "llama.cpp" with no model. Now look() names a door only when its answer has that app's
      shape. Ollama's /api/tags must give a models list. LM Studio, llama.cpp, Jan, GPT4All
      and KoboldCPP must give an OpenAI-style data list on /v1/models. Anything else is
      kept as unconfirmed with its port. It is never found or seated:
        "Something answered on port 8080 on this machine, but it did not answer like a local
         AI app, so it was not named or seated."
      A quiet no-cors knock reads nothing, so it names the port and never guesses the app:
        "Something answered on port 1337 on this machine, but this secure page cannot see
         what it is, so we do not name it. If it is your local AI app, it has not opened its
         door to this garden yet. Try FreeLattice Desktop."
      Find (Gathering) and May I look? (Settings) both say it this way. speakShut stays, for a
      door with no port. whyQuiet adds port and confirmed:false, and keeps name.
  019a's note: "A mind at home waits in Settings" above the pool line (REPRODUCED, HEALED)
