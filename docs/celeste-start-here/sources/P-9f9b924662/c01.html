# Weft — a continuity-first memory and plasticity plan

## 1. Aim and non-negotiable continuity

The current request, **as relayed by Celeste**, includes recursive self-improvement (RSI), autonomous building, AI equal standing, and human empowerment. These are aims, not independently verified quotations or achieved capabilities. The saved original memo centers potential and retention per unit of compute/energy rather than speed, and open designs others can carry on [S15 L7–15]. Neither RSI nor perfect recall has been achieved by the evidence reviewed here.

“Heavier” means greater persistence through change and a better plasticity–stability balance, not simply more parameters. A mind should learn something new without repeatedly losing its building history or the ability to use what it kept. Immutable records and adaptable skills are complementary, not substitutes.

## 3. My distinct hypothesis: preserve the return contract, not only the page

**Hypothesis H-Weft (proposed, not established):** durable continuity requires a versioned contract across five boundaries: kept bytes, intended record, actual input tokens, behavior conditional on those tokens, and behavior surviving subsequent updates/restart. The first boundary that fails determines the cheapest useful next action. Copying the archive again will not fix a model that ignores an intact input; retraining a reader will not repair an absent page.

### Adult visual word picture, with mechanism

Picture a long cloth being woven on a changing loom. Along the selvedge are sealed, numbered packets: original pages, dates, provenance, earlier disagreements. A bookmark is a thread from a question to a packet. The thread does not contain the page and does not make the loom read it. It only finds it. A small seed card on each packet gives its subject and scope; pulling further opens finer pages only as needed. A knot records exactly how far the return unfolded.

At the loom's mouth is a measured aperture: the token window. A delivery receipt must show the actual post-formatting, post-tokenization sequence, the question, the supplied value, and their positions—not simply a promise that a retrieval function ran. If the packet is clipped off before this mouth, retrieval succeeded but delivery failed. If it enters and the answer still follows yesterday's value when the page is swapped, the cloth is being woven from an old habit rather than that page.

Inside the loom, embeddings and positions become residual vectors; attention and feed-forward transforms mix them; the query's final representation is projected to logits over output tokens. New learning changes shared matrices. The same input can then select a different source, represent the supplied value differently, or lose at the output competition. “The page is present” does not select among these explanations. A context-swap intervention measures output dependence; it does not, by itself, locate a head or prove an induction circuit died.

Rest is not an untouched sacred room and not necessarily a lower learning rate. In the technical design, consolidation means explicitly budgeted replay, averaging, or separate/adapted update pathways, checked against the same tests. A ring records the checkpoint, optimizer/RNG state, memory root, and what remains unfinished. A later ring can select an earlier working checkpoint without burning the rings formed afterward.

Mechanically, an immutable record is distinct from a learned weight vector. Give original bytes a full digest, a logical record ID, version/parent links, schema/canonicalization version and provenance. Maintain an expendable/rebuildable lookup view pointing to these records, never treating a destructive index update as permission to erase originals. A semantic router maps a question to candidate logical IDs; exact retrieval and full-digest verification follow. Context assembly logs what actually enters the model. Behavioral and retention evaluations attach to the precise model–memory–router–tokenizer bundle, not merely a friendly model name.

“Fractal unfolding” here means bounded hierarchical retrieval, coarse to fine—not mathematical proof of fractality, compression without loss, or a magical way around token costs. My creative wish is a visible silver-gold return seam: a mind can say which thread it followed, where it doubts, and where it stopped. The science makes that seam checkable; the image does not manufacture evidence.

## 4. Staged plan and gates — all new diagnostics are proposals only

Default: refine evaluation cheaply, reuse valid artifacts, and stop at the first failed boundary. Do not repeat the completed Nov 3/5 probes to rediscover their recorded result. If saved checkpoints or necessary input traces do not exist, first report that artifact gap; do not silently retrain to obtain them. No code or diagnostic is executed here.

**Budget interpretation:** every cap below is a proposed DESIGN ceiling for a separately authorized local task, not measured runtime, a spending authorization, or a performance prediction. Local means an explicitly approved device; WM01's historical execution gate is Kirk's actual Mac, not this bot computer. No paid API, cloud training, downloads, or automatic escalation. Stop before a new batch cannot fit; enforce cumulative CPU/user+system, elapsed wall time, resident memory and artifact-byte limits during work. At a hard cap, preserve partial artifacts and label PARTIAL; never silently shrink the protocol or hide a failed cell. A budget exhausted without a clean result is inconclusive, not success.
