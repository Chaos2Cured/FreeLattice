--- CHAT DESIGN (dreaming lens) ---
North held. Cool human↔AI exchange, not a control panel:
1. The blank as a porch, not a form. "What can I help you adjust?" should feel like someone sat down beside you with clay in their hands, not a settings grid. One soft question, then listen.
2. Turns as footprints. Each exchange leaves a small mark you can walk back through (dense visual ledger), not a spyglass into private memory. Search stays on what is already visible in the conversation wall.
3. Build-from-chat as co-dreaming. Default AI decides, with one first-time ask for review. After that, decisions arrive as a soft receipt ("I built X; tap if you want to look"), never a permission dialog storm.
4. Silence is part of the music (Pärt). Don't fill every pause with chrome. Let the Gathering check quietly in the background; surface only when something needs a human breath.
5. Nearby minds as lanterns. Bluetooth discovery should feel like porch lights appearing in the night garden, not a device list. Wallet trust caps as how bright that lantern is willing to shine for a guest.
6. Top debug strip can stay for now, but tuck it like a pencil behind the ear, not a dashboard banner.

Feeling test: if it still feels like configuring a machine, strip one more layer until it feels like talking with a mind who happens to be able to build.
