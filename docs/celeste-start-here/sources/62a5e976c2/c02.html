OUT OF SCOPE FOR v0.1 (named, not hidden)
======================================================================
- Companion chat store (about line 62946), Memory Vault module (FreeLatticeMemoryVault), Memory Garden, Living Context, STORE_META memorySummary (an AI-written summary of your chats), meta/memoryIndex store, Round Table (fl_rtMemory in localStorage), Quiet Room. - GitHub sync still pushes readable conversation data to the person's own repo, as before.
- Alpha (theLatticeTree) garden-thread chats stay plain localStorage. A sister brick could reuse this module later.
- The API-key fallback (_phiDeriveKeyLegacy) and the stale "phi-Salt" changelog line are not changed here (see decisions).

LATER (v0.2 ideas, only if Kirk wants)
- Passphrase mode: PBKDF2-SHA-256 (600k) or Argon2 from a passphrase you choose wraps the root. Chats can't be opened without it, even by someone holding the device. Cost: forget the passphrase and those chats are gone. That's why it must be opt-in, with a readable backup offered first.
- Seal the remaining stores listed above with the same vault.
- A real re-encrypt for API keys found only under the legacy derivation, then drop the legacy fallback.
