  A. Composer row (one row at 1280; at 390 the textarea and Send own the row)
     [ + ]  [ textarea "Say something..." ]  [ Just me ]  [ Send ]
     - "+" is one labeled button, >= 44px, opens the menu (A2). Escape and a tap
       outside close it. aria-expanded tracks state. Focus returns to "+ Add" on close.
     - Just me keeps its job and its word (pool-honest). Give it title + aria-label
       "Just me: keep this chat on this device, never ask the pool".
     - Send unchanged in size and color (gold), still the strongest thing in the bar.
  A2. The + menu (one place for all the add-ons, in this order)
     1. Bring from Google Drive (drive/cloud SVG, NOT a laptop) -> flOpenDrivePicker()
        sub-line: "Give the mind a document from your Drive"
     2. Attach a file or photo (paperclip SVG) -> flAttachFile()
     3. Take a photo (camera SVG) -> same attach path through a hidden
        <input type=file accept="image/*" capture="environment">; show ONLY on touch devices
        where capture is supported; skip if not trivial and report.
     4. Scan a folder (folder SVG) -> flScanFolder()
     5. Speak (mic SVG) -> toggleVoiceInput(); keep its existing show/hide rule
     6. Make a picture (image SVG) -> handleImageGenClick()
     7. Search the web: on/off (globe SVG) -> proxies the existing #flChatSearchToggle. The
        visible "Search on" state line STAYS in the bar too (AUTONOMY: search visible in chat).
     8. Deep research / report: NOT on main today (Celeste grep found none). Do not invent it.
        Leave a quiet, disabled-free gap: simply no item. Note it in the report as a later ask.
     Menu style: --bg-card panel, --radius, --shadow, 1px --border, items 44px rows, icon 20px
     stroke SVG in --text-secondary, word in --text-primary --font-sm, hover/focus row
     --accent-glow, focus ring --border-focus. Opens upward from "+". Same handlers. Old buttons
     #chatAttachBtn / #chatScanFolderBtn / #chatDriveBtn / #micBtn / #imgGenBtn stay in the
     DOM (moved or proxied) so nothing that queries them breaks. The "..." More button may
     stay as a quiet alias that opens the same tray (layer, do not delete).

  E. Spacing + look
     - Fibonacci spacing tokens only (--space-xs/sm/md/lg). --radius / --radius-sm only.
       --font only (no serif fallbacks in the bar). Palette tokens only.
     - Motion: one Garden breath (~1.06 scale + gold tide) on menu open/press, off under
       prefers-reduced-motion. No bloom, no bounce.
     - No opacity below 0.75 for anything a person is meant to press.
     - Markers: v-chat-bottom-clarity-v0.1 on the menu, the "+" button, and the pill row.

  F. Part B: document return card (the mind hands a document back)
     - When a mind reply carries a document (a fenced block the house already understands, or

       name, type, size, and buttons "Save as PDF", "Save as MD", "Save as TXT".

     - "Save to my Drive" shows ONLY if Drive is already connected through the existing picker

     - textContent only; file name sanitized; no script/HTML executed; no keys in a card.
     - Card uses the same tokens as the menu. Buttons 44px. Marker v-chat-doc-return-v0.1.
     - Small new module docs/modules/chat-doc-return.js. Quiet when no document.
