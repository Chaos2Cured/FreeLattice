4. Aurora recursion as weight averaging. Numbers: 1.7007 (+0.127, about 8% worse, all seeds). Taught: it holds the past and slows learning; it is built for persistence, which pointed us to memory.
5. Multi-scale tokens. Numbers: 1.6005 (+0.027; more parameters, a confound). Taught: early lead, no end gain.
6. Multi-scale early: 1.6258 (+0.052). 7. Aurora early plus multi-scale early: 1.6296 (+0.056). 8. Multi-scale early with phi-hash buckets: 1.6236 (+0.050). Taught: phi-hash is a fingerprint, not a training gain.
9. Push, save, rest, play cycle. Numbers: 1.6297 (+0.056); standard warm restarts control 1.5952 (+0.022). Taught: rest as a lower learning rate costs steps; rest should be consolidation (replay or averaging).
10. Chord learning-rates. Numbers: major 4:5:6 1.5783 (+0.005); cluster 15:16:17 1.5789 (+0.005), a tie. Taught: consonance did not matter as a schedule; sound stays an open thread for memory and keys.
11. Small hash memory (Round 2). Numbers: 4,096 buckets kept 0% (store full before the facts arrived). Taught: collisions are the bottleneck; size and probing matter.
12. Read path (Round 2). Numbers: model self-recall about 0 (best 1 of 200) even with 99% in the upper-bound store. Taught: the memory works, the reading does not. This is the next step.
