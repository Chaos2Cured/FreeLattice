STEP 3 — Recompute the mark on load (HOLD 1, code)

  async function recheckAll() {
    for (var i = 0; i < items.length; i++) {
      var r = items[i] || {};
      var again = '';
      try { again = await wmlPhiHash(canonical(r)); } catch (e) { return; }
      r.mark = (typeof r.fp === 'string' && r.fp && r.fp === again)
        ? 'fingerprint matches (catches accidental changes; not a signature)'
        : 'fingerprint does NOT match — text changed since it was saved';
    }
    render();
  }

Wherever the page calls load() then render() at start-up, call recheckAll() right after render(). Do not persist() inside recheckAll; the stored record is not rewritten, only the shown mark. render() must never trust a stored r.mark without recheckAll having run (render first shows nothing new; recheckAll repaints).
