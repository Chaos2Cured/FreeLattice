       calm line of last intent. Examples (plain grandmother words):

         * last Build / Connect / Gathering action the person took on this device
       Optional Continue control that returns them to that place (Chat / Connect shelf /
       Gathering Ask) without inventing a new answer.
     - Soft, local, not a second chat history. One line. Not a thread. Not a replay.

  B. When it stays quiet (wrong-if)
     - If nothing recent (no last ask, no last action worth naming), the line stays quiet.
       Do not invent continuity. Do not show a placeholder that pretends a thread exists.
     - If Pause is in flight or Clear has wiped the thread / store this brick owns, Pause /
       Clear wins: no stale line that contradicts what the person just cleared.

       on this device (no first-open nag).
