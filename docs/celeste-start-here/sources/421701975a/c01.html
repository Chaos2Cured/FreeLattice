d) desktop/package.json: lattice-update.js added to build.files (or the packaged app would crash).
e) docs/app.html (and index.html, a byte copy): Settings, Self-Host card: a hidden row with
   "Check for updates" and "Open the release page", shown only when window.electronAPI has
   checkForUpdates (older shells and the website see nothing new). textContent only.
