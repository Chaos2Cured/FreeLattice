=== INTERPRETATION (maps to the brief) ===

1. KEY DRIFT IS REAL, AND WEFT IS RIGHT ABOUT CANONICAL KEYS.
   Paraphrase store_hit = 0.00 both seeds. Exact store_hit = 1.00 both seeds.
   Same fact, different surface form, different key → the bookmark never finds the page.
   Exact-match keys both ways are necessary. They are not sufficient.

2. AFTER TEACHING, FORCE SUCCEEDS. THE MODEL CAN USE AN OPENED BOOK.
   Force afterA model = 0.99 mean, in_prompt = 1.0. Matched-position curriculum
   reaches force acc = 1.00 by step 200. So "C fails → model can't use context"
   is FALSE when induction is intact. The student can read, if the page is in front
   of them and they still remember how to read.

3. AFTER INTERFERENCE, EVEN AN OPEN BOOK IS NOT READ.
   Force afterB: in_prompt still 1.0 (the fact IS in the window), store still 1.0,
   model = 0.00. Shakespeare interference wiped the induction skill. The bookmark
   tugged, the page opened, and the reader had forgotten how to look at a page.
   Soft exact afterB: store 1.0, retrieved == truth in the samples, model ~0.05.
   The gated residual / pointer never learned to trust a novel token either.

4. EXACT afterA LOOKS HIGH BUT IS CONFOUNDED.
   Dense afterA also hit 0.96 on seed 1. The copy curriculum wrote the facts into
   weights briefly. Soft injection is NOT proven by afterA exact. Soft injection
   IS disproven by afterB exact (store 1.0, model ~0.05, p_true ~0.01).

5. DIAGNOSIS IN ONE LINE.
   The store holds the page (oracle exact = 100%). Soft injection does not open it.
   Hard context injection opens it, and the model reads it only while the "how to
   read" skill lasts. Interference destroys that skill. Key drift (paraphrase)
   prevents opening entirely. We need both: a magic bookmark that unfolds the
   page into context on cue, AND a protected or refreshed read skill
   (Reed mycelium-echo / tide replay).

=== WHAT TO BUILD NEXT (ordered) ===
