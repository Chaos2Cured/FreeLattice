1. WHY
----------------------------------------------------------------------
GC's own note on 014: if the share door was already open, "Let this device help"
leaves it open, but the Pool card still says "trusted kin only". That is not true.
Now the note reads the real door:
  open  -> "This device helps people you have connected with, because the share
           door is open. Tap Only trusted kin to narrow it." plus a button
           "Only trusted kin" that sets the door to kin (one tap) and repaints.
  kin   -> the old line, "This device helps trusted kin only..."
  pause -> "Helping is on, but the share door is paused, so no one can use this
           device right now."
  off   -> same shape, "sharing is off on the share door".
The tap still never narrows an open door by itself (the person chose open).
