## Exact source excerpt, characters 2939–6359

DESIGN CHOICES (the honest ones)
  CDN or vendor: VENDOR. The engine code is @mlc-ai/web-llm 0.2.85 (Apache-2.0), package/lib/index.js,
    one self-contained ES module (no imports), about 6.6 MB, kept on this site at
    docs/lib/web-llm/web-llm-0.2.85.js and loaded with import() only after a human tap.
    Why: the code then comes from thelatticetree.com, pinned and checked by sha256, never changes
    under us, and a school filter that blocks jsdelivr does not break the card. Cost: 6.6 MB in the
    repo (served only to people who tap), and a new version is a new file, by hand. There is no CDN
    fallback on purpose. The card says plainly where everything comes from:
      "Where the files come from: the engine code is kept on this site (WebLLM 0.2.85, Apache-2.0).
       The mind's files come once from huggingface.co, and its small engine file (about 5 MB) from
       raw.githubusercontent.com. They are kept in this browser, so the next visit downloads nothing.
       Your questions and its answers never leave this device."
    The weights cannot be vendored sensibly (hundreds of MB); they come from WebLLM's own prebuilt
    list (Hugging Face mlc-ai repos, model libs v0_2_84 on raw.githubusercontent.com).
  Models (real WebLLM 0.2.85 prebuilt ids; download = sum of the Hugging Face repo files, measured
  2026-10-09; graphics memory = WebLLM's vram_required_MB):
    SmolLM2-360M-Instruct-q4f16_1-MLC   about 210 MB, about 0.4 GB GPU, Apache-2.0   (smallest)
    Qwen2.5-0.5B-Instruct-q4f16_1-MLC   about 290 MB, about 0.9 GB GPU, Apache-2.0   (good first mind)
    Llama-3.2-1B-Instruct-q4f16_1-MLC   about 710 MB, about 0.9 GB GPU, Llama 3.2 Community License,
                                        and the card says "not an open source license; it has its own
                                        use rules"
    Qwen2.5-1.5B-Instruct-q4f16_1-MLC   about 880 MB, about 1.6 GB GPU, Apache-2.0   (biggest here)
    Each also has a q4f32_1 twin (same download, a little more GPU: 0.6, 1.1, 1.1, 1.9 GB). The card
    picks the twin when the adapter lacks shader-f16, so older chips still work.
    Not offered: Qwen2.5-3B (its license is research-only, not Apache). Nothing AGPL.
    Note: the paste brief guessed Qwen2.5-0.5B at 0.4 to 0.9 GB. The real download is about 290 MB;
    0.9 GB is the graphics memory it needs. The card shows both, separately.
  WebGPU: navigator.gpu plus requestAdapter() (local, no network), checked on mount. With none, the
    card offers no download and says:
      "This browser cannot run a mind inside the page (it has no WebGPU here). That is all right,
       nothing was downloaded. You can still talk to a mind: in Trusted kin, make an asking card,
       then join a room in the Device Pool and use a trusted device's mind. Chrome or Edge on a
       laptop usually has WebGPU."
  Only a human tap downloads: the four model buttons show size, memory and license first; then
    "Download about N MB and wake (id)". wake(), seat(), giveBack() and removeFiles() refuse unless
    called with human === true from a click handler. Mounting loads nothing. If the files are already
    kept, the button says "Wake (id) (already kept here, nothing downloads)".
  Naming: UI copy names models only by their ids. No lab is named as a mind's origin. The license
    line names the license (Llama 3.2 Community License), which is part of the id's own terms.
