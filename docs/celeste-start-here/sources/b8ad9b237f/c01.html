     packTag "dev" and never offers an update.
  b. From the next release on, bump the version via extraMetadata (5.8.1 for desktop-packs-v0.3)

  c. Old packs (v0.1, v0.2) have no build-info.json. Treat "no file + version 5.8.0" as
     "desktop-packs-v0.1 or v0.2, unknown which", and offer the newest release honestly:

  d. Compare by tag: desktop-packs-vMAJOR.MINOR[-rcN]. Full releases only (no draft, no

2. THE UPDATE CARD AND BUTTON
  a. lattice-update.js: ADD pickLatestPack(releases) beside pickLatestDesktop (keep it), matching
     /^desktop-packs-v(\d+)\.(\d+)(?:-rc(\d+))?$/, and ADD checkPacks() that returns data only:
     { current, latest, newer, assets: { winSetup, winPortable, appImage, deb, macZip, macDmg },
       sha256 (from the GitHub asset digest field when present), notes url }.
  b. Check on startup once, 30 s after the window loads, then once a day while running. No check
     more often. Failure is silent in the card ("Could not reach GitHub just now") and never
     blocks anything. A Settings "Check for updates" button checks on tap.
  c. Card (in-page, via preload IPC, textContent only), only when newer:
       A new version is ready
       FreeLattice desktop-packs-v0.3 (you have desktop-packs-v0.2).
       This app is not signed yet. Your computer may warn you. The download comes from
       github.com/Chaos2Cured/FreeLattice and is checked against its SHA-256 before it opens.
       [Update]  [Not now]          (both at least 44px)
     "Not now" hides it for that version until the next day. No red, no countdown.
  d. What Update does, per OS (pick the platform from process.platform and how it was installed):
     - Windows NSIS Setup install: electron-updater (provider github, owner Chaos2Cured, repo
       FreeLattice), autoDownload false, autoInstallOnAppQuit false. Tap Update -> downloadUpdate
       with a progress line -> "Ready. Restart now?" [Restart now] [Later]. Restart now ->
       quitAndInstall. Requires latest.yml + blockmap on the release (step 3).
     - Windows Portable (process.env.PORTABLE_EXECUTABLE_DIR set): electron-updater cannot swap a
       portable. Download the new Portable .exe to Downloads, check SHA-256, then
       shell.showItemInFolder. Words: "Saved to Downloads. Close this window and open the new one."
     - Linux AppImage (process.env.APPIMAGE set): electron-updater (latest-linux.yml), same taps
       as Windows Setup.
     - Linux .deb: download the .deb to Downloads, check SHA-256, show in folder. Words: "Open it
       with your software installer, or run: sudo apt install ./FreeLattice_..._Linux.deb".
     - Mac (unsigned, Squirrel.Mac needs signing so it cannot auto-swap): download the .dmg (zip
       if no dmg) to Downloads, check SHA-256, then shell.openPath it. Words: "Drag FreeLattice to
       Applications and choose Replace. If Mac says damaged, see install.html#mac-damaged-
       quarantine."
     - Any SHA-256 mismatch: delete only the file this run just downloaded, say "That download did
       not match. Nothing was opened." and stop.
  e. Keep the v0.1 menu item; point it at the new check so the menu and the card agree.
  f. Downloads go only to https://github.com/Chaos2Cured/FreeLattice/releases/download/ and the
