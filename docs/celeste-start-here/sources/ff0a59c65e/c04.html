    ranges, the refusals and the future hook (exact text in Appendix A). API:
      zoneOf(raw)      'this' | 'home' | 'public' | 'name' | 'invalid', from new URL(...).hostname
      isOn()           localStorage fl_homeNet === 'on'
      allows(raw)      'this' always; 'home' only while on; a '/'-relative same-origin proxy path
                       (/ollama) is allowed because it never leaves the page's own origin
      address()        fl_homeNet_addr
      useAddress(raw, kind)  home + on only: writes fl_homeNet_addr and fl_ollamaHost (or
                       fl_lmstudioHost for kind 'lmstudio' / port 1234), then forget()
      refusalFor(raw)  plain sentences, each ending "Nothing was sent.":
                         public: "That address is on the public internet, so it is blocked. Nothing was sent."
                         name:   "Type the number address, like 192.168.1.50. A name can point anywhere, so names are not used. Nothing was sent."
                         home while off: "That is a computer on your home network. Turn on \"Also use a computer on my home network\" beside the Box field in Chat to use it. Nothing was sent."
                         invalid: "That does not look like an address. Nothing was sent."
      setOn(on)        one tap. On: fl_homeNet='on', remembered address written back.
                       Off: fl_homeNet removed, non-loopback fl_ollamaHost / fl_lmstudioHost
                       removed, fl_homeNet_addr kept. Then forget(), say(''), paint(),
                       FLBoxPointer.syncFromStorage, input value, noteStatus.
      migrate()        once (fl_homeNet_seen), per choice C8.
      init()           migrate + paint + bind the switch 'change' once.
      paint()          mode words ("This computer only" / "This computer and my home network"),
                       checkbox + aria-checked, the line (textContent = LINE, hidden unless on),
                       Box placeholder ("127.0.0.1:11434" / "192.168.1.50").
      say(msg)         #flHomeNetRefusal textContent + hidden.
      LINE             Kirk's line, exact.
    Also: window.flHomeNetAllowsBase(b) (small helper for other callers).
