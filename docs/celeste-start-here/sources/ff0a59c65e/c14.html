# Connect Boot Probe v0.1 (F1, F2, F3, F4)

One cold-start look, one voice at boot, LM Studio in Connect, and a home-network switch.
FreeLattice · 28 September 2026 (after env heal v0.1.1 and Tree any-model v0.1).

**Marker:** `v-connect-boot-probe-v0`

**Locks:** Layer, never delete. Root `sw.js` byte-identical to main; `docs/sw.js` untouched. `index.html` identical to `docs/app.html`. Shared `docs/modules/fl-connect.js` byte-identical with Alpha. `textContent` for every new string. Allowlist never bare `*`. No confirm(), no approval screens. Quiet Room shut. Named five stay five. Family uncapped.

## Why

A returning cold boot asked the same local minds about 38 times in its first seconds (three full Bridge scans, five tags calls) and could speak twice (toast plus banner). Now it asks about 16 times (one Bridge scan, two tags calls, LM Studio once) and speaks once. A cold `#connect` for a new person made about 73 local requests and let the toast and the welcome overlay land on top of Connect. When LM Studio answered, the badge still said "Yes, use Ollama". The Box pointer saved any address, including public ones.

## What changed

| Heal | What |
|---|---|
| **F2** | `FlConnect.bootProbe()`: one in-flight promise, 5 second cache (`BOOT_TTL_MS`), no timers. Connect, the toast, autoDiscover, Zero-Click and the Bridge detect all read the same look. `resolveOllamaBase` joins one in-flight call in `app.html`. `flForgetLocalLook()` clears both when an address changes. |
| **F1** | `window.FlColdStart` owns the cold start: runs the shared look once, seeds the resolved base, paints the Bridge chip, then speaks once (or not at all when Connect, the welcome overlay, or a chosen mind is already in front). Old boot paths step aside when the owner is present. Last tab and `#connect` are decided before the welcome overlay. |
| **F3** | LM Studio is a first-class door in Connect: "LM Studio is ready, pick a mind", tap to choose, `fl_provider` becomes `lmstudio`, and Ollama stays untouched. The badge says "LM Studio is ready on this computer." with "Yes, choose a mind". Builds on the Tree any-model paste (mergeFound, chosenModelName, aria-pressed). |
| **F4** | `FLHomeNet`: "This computer only" by default and one switch, "Also use a computer on my home network". Private IPv4 only (10/8, 172.16/12, 192.168/16). Refused always: public addresses, names other than localhost, 169.254/16 (link-local and the cloud metadata address), 100.64/10, IPv6 other than ::1. Remembered until changed; one tap reverts. |

## Choices (stated)

- 169.254/16 is refused (it is also where cloud metadata lives).
- Only IPv4 numbers count as home. Names like `mybox.local` are refused because a name can point anywhere.
- Settings Ollama Address stays 127.0.0.1 only unless the same switch is on.
- Connect's own port field and LM Studio look stay on this computer.
- An old saved home address turns the switch on (it was already in use). An old public address or name is set aside, never used, and the Box pointer says so.
- Future hook: signed remote minds will come through a separate, signed path. They never widen these ranges.
