2. DECISIONS AND CHOICES (stated, so review is quick)
======================================================================

Kirk's decision (F4, verbatim intent):
  - Default "This computer only".
  - One clear switch: "Also use a computer on my home network".
  - When on, the person types an address once and sees exactly:
      "Only addresses inside your home network are allowed (like 192.168.x.x). Public internet addresses are always blocked."
  - Private ranges only. Public addresses always refused. Remembered until changed. One tap
    reverts. No confirm(), no approval screens. Future hook for signed remote minds.
