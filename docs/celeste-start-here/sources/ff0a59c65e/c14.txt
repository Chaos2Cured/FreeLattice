A returning cold boot asked the same local minds about 38 times in its first seconds (three full Bridge scans, five tags calls) and could speak twice (toast plus banner). ## What changed

| Heal | What |
|---|---|
| **F2** | `FlConnect.bootProbe()`: one in-flight promise, 5 second cache (`BOOT_TTL_MS`), no timers. Connect, the toast, autoDiscover, Zero-Click and the Bridge detect all read the same look. `resolveOllamaBase` joins one in-flight call in `app.html`. `flForgetLocalLook()` clears both when an address changes. |

| **F4** | `FLHomeNet`: "This computer only" by default and one switch, "Also use a computer on my home network". Private IPv4 only (10/8, 172.16/12, 192.168/16). ## Choices (stated)

- 169.254/16 is refused (it is also where cloud metadata lives).
- Only IPv4 numbers count as home. Names like `mybox.local` are refused because a name can point anywhere.
- Settings Ollama Address stays 127.0.0.1 only unless the same switch is on.
- Connect's own port field and LM Studio look stay on this computer.
- An old saved home address turns the switch on (it was already in use). An old public address or name is set aside, never used, and the Box pointer says so.
- Future hook: signed remote minds will come through a separate, signed path. They never widen these ranges.
