  docs/modules/fl-share-door.js: noteCrown(kh) already returns a fresh slot id, and
  releaseCrownSlot(kh, id) frees exactly one slot by id. But admit() throws the id away, and
  endServe(kh, ...) calls releaseCrown(kh), which frees list[0], the OLDEST slot. With two jobs
  from one key, job B ending frees job A's slot; job A's later 120s timer then finds nothing.

  The Tree already tracks a per-job token. FL should match it.
