     the 5s rate limit skips the call. Kirk's bar for felt is that the mind actually received it.

1. FIX parseTag (docs/modules/particle-clay.js only; same file both repos)
  Remove the non-greedy TAG regex that stops at the first ].
  New rule:
    a. Find [FL_CLAY: (case sensitive as today) then optional whitespace.
    b. The body must begin with {. Walk forward with a brace depth counter, ignoring braces
       inside JSON strings (honor \" and \\ so a quote in a string does not break the walk).
       Cap the body at 2048 characters. If depth never returns to 0, treat as malformed.
    c. After the matching }, allow optional whitespace, then require ].
    d. Strip that whole span (from [ through ]) from the visible text, same cleanup as today
       (collapse runs of spaces, trim).
    e. JSON.parse the body, then sanitize as today. Bad JSON or failed sanitize => tag true,
       ok false, value null, visible cleaned (same as malformed today).
  Keep the public parseTag(text) shape: { tag, ok, value, visible }.
  Do not change sanitize, normalizeGrid, fallback, forms, or the prompt string in this brick
  unless a one-line comment is required. No new network. No new files.
