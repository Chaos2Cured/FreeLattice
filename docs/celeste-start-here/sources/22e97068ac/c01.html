4. HONEST ANSWERS
  a. "Later" truly defers: the ask stays pending, and the mind may not re-ask the same page
     for 24 hours (SEAL_ASK_COOLDOWN_MS = 86400000). The pending ask stays visible in the
     Notebook with its badge. Chat line: "Saved your answer for later."
  b. "No, don't seal" declines: line "Declined the seal." and the same cooldown before the
     mind may ask again for that page. Neither writes a receipt; both write a small local note.
  c. One state per page: unsealed / asked / later / declined / sealed. A later Seal it moves
     the page to sealed and the panel shows only "Sealed" plus the receipt; the old
     "Declined the seal." line is layered into history (kept in the page's log, shown greyed
     under "Earlier answers" inside details), never beside "sealed" as current state.
  d. Persist pending asks in the existing FreeLatticeWorkspace store (new object store or key
     "sealAsks", summary + version + reason + askedAt + state only, never page text). On load,
     restore them to the dock and Notebook. A pending ask for a page that changed version is
     marked "stale, ask again" rather than sealing the new version.
