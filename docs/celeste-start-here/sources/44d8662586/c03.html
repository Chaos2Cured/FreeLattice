+# Gathering: bring your own key, v0.1
+
+Local minds and cloud minds you choose, side by side in the Gathering chairs, any order.
+Alpha layer, marker `v-tree-gathering-api-keys-v0`. September 30, 2026.
+
+**Temperature:** Mom seats her own Claude in the cortex chair, her llama in memory, and taps between them like passing the salt.
+
+**Locks:** Layer, never delete. Local doors stay 127.0.0.1 only. The cloud road is a fixed list of nine https providers, no custom hosts. The key stays in this browser (localStorage, or sessionStorage for this visit only) and goes only to the chosen provider, in its own header, never in a URL. No key in gatheringBinds, seats, thread history or export. Files stay on this machine; a cloud chair hears only that a file stayed here. No confirm(). No innerHTML. textContent only. fl-connect.js untouched. No sw.js on Alpha.
+
+## What it does
+
+- In the Gathering, tap a chair, open **Seat a mind by API key**: provider, model (suggestions, or type any name), your key, optional "only for this visit". **Save and seat** seats it in that chair at once.
+- Seats saved for a provider stay offered next to local minds while its key is in this browser. Forget removes the key; the seat waits until a key returns.
+- Tap a chair to let it speak. The thread heart says where words go: "Listening: gpt-4.1-mini through OpenAI. Your words go to OpenAI. Your key stays in this browser."
+- Honest failures, each in plain words: key not accepted, slow down, model not taken, could not reach, quiet. Nothing is invented.
+
+## Where the key lives (said in the panel, word for word)
+
+Your key stays in this browser on this device. theLatticeTree has no server and never sees it. It goes only to the provider, with each message, when a chair seated through it speaks. Your words go there too, so they leave this computer; files you add stay here. Anyone using this browser profile could find the key. Forget removes it.
+
+## Map (why it is shaped this way)
+
+- FreeLattice app.html keeps one key (`fl_apiKey_enc`, AES-GCM with a device key that sits beside it in the same localStorage) for one provider at a time, and calls providers straight from the browser. The Tree is another origin, so it cannot read FreeLattice's key; it keeps its own, per provider.
+- Every listed provider answers a browser preflight from https://thelatticetree.com (checked Sep 30). No Bridge is needed and the Bridge stays local-only.
+- Cloud seats ride the existing Gathering binds as `url: 'cloud:<provider>'`, so local-mind-probe.js and fl-connect.js need no change and the Tree any-model paste is untouched.
+
+## Later (not built)
+
+- Ask a provider for its model list (GET /models with the key).
+- A custom OpenAI-compatible host (needs Kirk's call on the lock).
+- Cloud minds in Settings, Round Table and Workshop (today only Gathering chairs).
+- Streaming replies.
