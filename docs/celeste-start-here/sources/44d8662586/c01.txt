    fl_apiKey_enc (AES-GCM, PBKDF2 from fl_device_encryption_key + provider name) and
    fl_apiKey_provider; legacy plaintext fl_apiKey migrates. The device key sits in the same

    the page. Switching provider re-encrypts the one key (reEncryptApiKey).

      openai-compatible: Authorization: Bearer <key>, POST url, {model, messages, stream:true}

                 anthropic-dangerous-direct-browser-access: true, system split out, max_tokens
      google: x-goog-api-key header, url .../models/<model>:streamGenerateContent?alt=sse
              (some other FL call sites still put ?key= in the URL: 52028, 61741, 64030)
      openrouter adds HTTP-Referer + X-Title.
    No Bridge in the cloud path. The Ollama Bridge (11435) and Agent Bridge (3141) are local only.
1.4 Active model: FLActiveModel (app.html 36228) = { model, provider, source } in
    fl_ollamaModel / fl_provider / fl_modelSource; fl-connect.js markUserChoice calls it on FL
    and is a quiet no-op on the Tree.
1.5 CORS: checked Sep 30 with preflights from Origin https://thelatticetree.com, no keys:
      groq 204 *, openrouter 204 *, openai 200 (echoes origin), anthropic 200 * (allows the
      browser header), google 200 (echoes origin, allows x-goog-api-key), xai 200 *, mistral 200 *,

3. THE DESIGN (smallest clean brick)
======================================================================
- A cloud seat is an ordinary Gathering bind with url 'cloud:<providerId>':
    { tag: 'general', model: 'gpt-4.1-mini', url: 'cloud:openai' }
  So setChairBind, setSpeakingChair, resolveSpeakMind, any-model's merge, and fl-connect's
  "keep binds" all work unchanged. No key ever enters the bind.
- New module docs/modules/tree-cloud-minds.js (window.TreeCloudMinds):
    PROVIDERS: fixed, https only: groq, openrouter, openai, anthropic, google, xai, mistral,
    deepseek, together (urls and shapes mirror FL PROVIDERS; suggestions from FL's ids;
    any model name may be typed, checked against /^[A-Za-z0-9._:\/@+-]{1,120}$/).
    Keys: fl_tree_cloud_keys { v:1, keys:{id:key} } in localStorage ("on this device", default)
    or sessionStorage ("only for this visit"). One key per provider, any number of providers.
    Seats: fl_tree_cloud_seats [ {provider, model} ] (no keys, cap 16).
    seatOptions(): seats whose provider has a key now.
    send(mind,msgs): one POST to that provider's fixed url, key in its own header
      (Bearer | x-api-key + anthropic-dangerous-direct-browser-access | x-goog-api-key),
      credentials 'omit', referrerPolicy 'no-referrer', 120 s abort, non-streaming.
      Rejects { reason:'cloud', cloudText } with plain words: key not accepted (401/403),
      slow down (429), model not taken (400/404), other status, quiet, could not reach,
      no key in this browser (zero requests), unknown provider (zero requests).
    heartLine(mind), honestNote(id), mountKeyPanel(host, onSeat).
- The thread: a cloud listener goes to TreeCloudMinds.send; the heart and the waiting line name
  the provider; a cloud chair hears "[a file stayed on this machine]" instead of a file excerpt
  or name; honest errors are the module's own words.
- The panel lives inside the Gathering chair picker: <details> "Seat a mind by API key":
  Provider, Model (datalist), API key (type=password, autocomplete=off), "Only for this
  visit", "Get your <Provider> key" link, the honest note, Save and seat, saved keys with
  their last 4 characters and a Forget button each. Save seats that chair at once.
  No confirm(): Forget is immediate and says "Forgotten. The <Provider> key is gone from
  this browser."
- Honest note (exact words):
  "Your key stays in this browser on this device. theLatticeTree has no server and never sees
  it. It goes only to <P>, with each message, when a chair seated through <P> speaks. Your words
  go to <P> too, so they leave this computer; files you add stay here. Anyone using this browser
  profile could find the key. Forget removes it."
