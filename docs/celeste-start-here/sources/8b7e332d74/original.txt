3. WHAT THE DIFF DOES (13 files, +366 / -8; changed old lines kept as "before" comments)
----------------------------------------------------------------------
a) desktop/data-proxy-worker/search-route.js (new): GET /search?q=words on the freelattice-data
   worker. Brave Search if the BRAVE_API_KEY secret is set; otherwise DuckDuckGo Instant Answer
   plus Wikipedia search (keyless, reference answers, not live news). Returns
   { items: [{title, snippet, url}], source }. FreeLattice origins only (freelattice.com, www,
   chaos2cured.github.io, codeberg page, http://127.0.0.1:port), no console logging, no storage,
   Cache-Control no-store, tracking params stripped. No bare * CORS.
b) desktop/data-proxy-worker/worker.js: imports it and routes /search before anything else
   (fetch(request) becomes fetch(request, env)). The chart route is unchanged.
c) docs/modules/web-tool.js: DEFAULT_SEARCH_ENDPOINT = our worker /search, used when the device
   has no endpoint of its own (window.FL_SEARCH_ENDPOINT, then localStorage.fl_searchEndpoint
   still win; the value none keeps the old dormant state). No consent chip by default; a new
   isAskFirst() (localStorage.fl_searchAskFirst = 'true') brings the chip back. Off-switch
   (fl_searchEnabled = 'false') unchanged. The ledger still never stores the query.
d) docs/app.html (and index.html, a byte copy): Settings card gets honest words and an optional
   "Ask me before each search" switch; status line "On. The AI may search when it needs to, and
   each search shows in the chat. Searches go through our worker."; the system prompt and the
   follow-up prompt no longer claim a consent that did not happen (only when ask-first is off);
   every search answer starts with "_Searched the web for "..." through our own search worker._"
e) docs/privacy.html: the old "search stays off" row retired in a comment, a new row says where
   the words go (our worker, then Brave or DuckDuckGo and Wikipedia), and a Newer note.
f) docs/see-for-yourself.html: "The internet" line now says search is on by default, shown in
   chat, through our worker, with the off-switch; other tools still ask first.
g) docs/index.html (landing): the "closeMenu is not defined" error at line 2078. The close button
   now calls window.closeMenu() when clicked instead of naming closeMenu before it exists.
h) docs/scripts/smoke-honesty-terms-three-doors.js: its privacy check is layered to accept the
   retired old row plus the new one (old line kept as a comment).
i) tests/smoke.js: 8 new web-search-on checks. docs/library/WEB_SEARCH_DEFAULT_ON_v0.1.md (new).
   desktop/data-proxy-worker/DEPLOY.md: deploy steps. Ledger: your entry (section 5).
