A. NEW docs/modules/mind-make.js (FL)
  Purely additive. One window.FLMake = { version: 'v0.1', parse, onReply, register, kinds,
  consent, ledger } for the smoke.
  1. THE TAG. One tag for every mind-initiated act:
       [FL_MAKE:{"kind":"clay|image|music|learn|research","why":"...","ask":"..."}]
     Balanced scanner like 037b (count braces, respect strings and escapes), 2048-char cap per
     tag; over the cap or bad JSON is dropped quietly and the tag text is removed from what the
     person reads. kind is required; why and ask are plain strings, trimmed, capped at 280 chars
     each, shown with textContent only. At most one offer per reply.
  2. THE REGISTRY. FLMake.register(kind, { offer, run, describe }). 047 registers only "clay",
     which on Yes hands the ask to the existing FLClay path (no clay file edited). Any kind with
     no register call shows one quiet line "Your mind wanted to make <kind>. That is not ready
     yet." and is otherwise ignored, so rings can land in any order. An unknown kind never throws.
  3. THE CONSENT RECORD. Per person, per kind: "Let your mind offer to make things?" Off until the
     person says Yes. One exception, written now and used in 050: kind "learn" follows the
     AUTONOMY wish (on by default, one-tap off, shown honestly in Settings). In 047 nothing runs
     for learn; the toggle just exists. Pause and Quiet Room always win over every consent. One
     shared rate gate for all kinds (at most one offer per 10 minutes per chat; report the number
     you chose if different).
  4. THE OFFER CARD. Below the reply, never over Send, the seal ask, the honest label or the clay
     corner. Shows the kind, the why and the ask. Buttons: Yes / Not now / Never for this kind,
     each 44px tall at least, keyboard reachable, Escape = Not now. "Never for this kind" turns
     that kind's consent off and says so plainly. No sideways scroll at 390 and 1280. Reduced
     motion respected.
  5. THE LEDGER RECORD (old brick "My ledger", folded in). Every act (Yes, Not now, Never, and
     the result when run) appends one record to the mind's own ledger: t (ISO UTC), lambda (next
     index for that mind), delta "kind|why|result hash" (result hash = first 8 hex of sha256 of the
     result, or "none"), omega the mind's name, sigma, psi = first 8 hex of sha256 of
     t+lambda+delta+omega+sigma concatenated (crypto.subtle). Keep it in mind-workspace's
     database by a NEW store or a new module-owned key; do not edit mind-workspace.js (if you
     cannot avoid it, stop and report). The person can read and export it (JSON, local download)
     from the mind's Notebook under a "Ledger" tab; the person cannot edit or delete the mind's
     lines. Append-only.
  6. Load it in docs/app.html AND index.html with defer, after particle-clay.js. One call from the
     existing reply path to FLMake.onReply(text), as an added line next to the clay tag hook
