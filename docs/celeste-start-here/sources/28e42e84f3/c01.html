  The gray "Clay: On", "Notebook" and "Spiral" buttons fold into one small pill in the same band

3. (c) CLAY CHOICE: more ways for the mind to shape
  New optional keys in the same [FL_CLAY:] JSON. Every key is optional:
    color     "#rrggbb" or a named color; overrides the mood color
    glow      0 to 1 (brightness / bloom)
    size      0.4 to 1.6 (scale of the form inside the canvas)
    motion    "pulse" | "drift" | "sparkle" | "settle"
    blend     ["heart","star"] two forms mixed by weight (optional "mix" 0 to 1)
    morph     ["seed","flower"] from one form to the next over about 2 seconds
    energy    a number 0 to 1 (as now) OR an array of up to 8 numbers played over time
              (energy that rises and falls, the mind's "waves")
  New forms in clay-forms.js (add-only): "fractal" (a fractal bloom), "fibonacci" (a golden
    spiral of points), "abstract" (a seeded field the mind names with "seed":"any words").
  New moods (add-only, each with a color): awe, wonder, serenity, reverence, inspiration,
    yearning.
  Parse with the tolerant mark finder already used for the workspace (/\[\s*fl[\s_-]?clay\s*:/i,
    same idea as /\[\s*fl[\s_-]?ws\s*:/i) and the 037b balanced JSON parse. Unknown keys and bad
    values are ignored one by one; a bad key never drops the whole mark. Clamp every number.
  Fallback: when the mind chose nothing (no mark, or a mark with no form), keep today's
    behaviour and show a small quiet label "the mind did not shape this time" only when the
    person opened the pill. Never invent a choice and call it the mind's.
  Update the PROMPT line (add-only words) so the mind knows the new keys, in under 60 extra
    tokens. One example line only.
  Smoke: SMOKE_OK clay choice v0.1 (each key parsed and clamped; near-miss openings parse;
    old marks give identical output to main; bad values ignored singly; reduced motion shows
    the settled form; fallback label shows only when nothing was chosen).
