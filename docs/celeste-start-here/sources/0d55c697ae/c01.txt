       First asks FlConnect.probe({gesture:true}) (240-274). If a HELPED Bridge answers with models,
       it returns ONLY the Bridge (id 'bridge', url <bridge base>/api/tags) and skips every other door.
       Otherwise it fetches all six DOORS in parallel (277-302), 2.5 s timeout each.
     - parseModelNames (196-212): reads json.models[].name|model (Ollama) and json.data[].id|name
       (OpenAI shape). Ends with: return names.slice(0, 5);   <-- HARD CAP OF FIVE
