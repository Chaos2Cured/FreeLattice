1.6 Bridges and trust (why the Agent Bridge is not the road here)
  - Ollama Bridge (FreeLattice bridge/proxy-core.js, 127.0.0.1:11435 default): origin allowlist
    already names https://thelatticetree.com (never *). No pairing, no token. It proxies ONLY to
    Ollama at 127.0.0.1:11434. LM Studio models are not reachable through it.
  - Agent Bridge (FreeLattice tools/agent-bridge.js, 127.0.0.1:3141, locked by #120): not used by the
    Tree at all today (grep finds no 3141 / agent-bridge in Alpha docs/). GET /models is not
    token-gated but is Ollama-only; every POST (including /inference) needs a paired token
    (needsToken: "every POST and any other verb"), and /inference defaults model to 'llama3.2',
    the poetry route to 'qwen2.5:7b'. Its OLLAMA_BASE default is http://localhost:11434.
    Routing Tree chat through 3141 would ADD a trust gate (pairing) for a purely local act and
    would touch #120's lock files. Decision for v0.1: do not route through 3141. Keep the Tree on
    the Ollama Bridge (11435) and direct loopback doors. Say so in the doc.
  - HTTPS honesty: on https://thelatticetree.com the browser may block http://127.0.0.1:1234 unless
    LM Studio's own server has CORS enabled. That is outside our code; we add one honest line.

5.1 New helper after modelOnList (465-472):

  // v-tree-any-model-v0: find a prior model at any found door (the Bridge and 11434 are the same Ollama)
  function doorFamily(url) {
    var u = String(url || '');
    if (/\/v1\/models$/i.test(u)) return 'openai:' + u.replace(/\/v1\/models$/i, '');
    return 'ollama';
  }
  function findModelAnywhere(minds, name) {
    if (!name) return null;
    var i;
    for (i = 0; i < minds.length; i++) {
      if (modelOnList(minds[i].models || [], name)) return minds[i];
    }
    return null;
  }
