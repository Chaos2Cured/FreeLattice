Goal in Kirk's words: any locally downloaded model is usable and changeable in any order on
theLatticeTree, with no friction, via Connect/Bridge, 127.0.0.1 only.

"Any order" means all of these sequences end with the model the person tapped last, and every
other model still one tap away:
  Settings Find -> tap star -> Connect tap -> tap star -> Gathering chair pick -> Connect tap
  Connect tap -> Settings Find -> tap star
  Settings Find (Ollama + LM Studio both up) -> Connect tap (Ollama) -> choose LM Studio door
  Bridge up -> Find -> Bridge down -> Find (direct 11434) -> chosen model kept
  Seven or more models at one door -> the 6th, 7th, 12th are all choosable

1. THE MAP: how local models are found, listed, chosen and switched today
======================================================================

1.1 Discovery (two separate doors that write the same key)

  A) Settings grandmother face: docs/modules/local-mind-probe.js (937 lines on 22b913e)
     - DOORS (lines 54-61): loopback only, well-known ports:
         Ollama 127.0.0.1:11434/api/tags, LM Studio 127.0.0.1:1234/v1/models,
         llama.cpp 8080, Jan 1337, GPT4All 4891, KoboldCPP 5001 (all /v1/models).
     - look() (238-304): runs only after a tap ("Find local minds", data-mind-ask).
       First asks FlConnect.probe({gesture:true}) (240-274). If a HELPED Bridge answers with models,
       it returns ONLY the Bridge (id 'bridge', url <bridge base>/api/tags) and skips every other door.
       Otherwise it fetches all six DOORS in parallel (277-302), 2.5 s timeout each.
     - parseModelNames (196-212): reads json.models[].name|model (Ollama) and json.data[].id|name
       (OpenAI shape). Ends with: return names.slice(0, 5);   <-- HARD CAP OF FIVE
     - tryAddress(raw) (306-336): the paste field. Prefixes http:// and fetches
       <base>/api/tags, <base>/v1/models, <base> in turn. NO LOOPBACK CHECK. Any host is fetched.
     - onFound -> entryFromFoundList(foundList, name, url, prior) (474-534) -> remember(entry).

  B) Connect card (shared core): docs/modules/fl-connect.js (681 lines on 22b913e, 710 on #83)
     - probe() (166 main / 176 #83): saved Bridge port, then (full scan only) 11435-11445, then
       direct 11434. Ollama API only (/bridge/health + /api/tags). No LM Studio, no /v1/models.
     - render() builds one .flc-models list per door with EVERY model (no cap). fillModelLists
       (456 main / 473 #83) makes one button per model; tap -> remember({ name, base, port }).
     - remember() Alpha branch (text anchor "if (isAlpha()) {" inside function remember, main 308-331,
       #83 320-343) writes a BRAND-NEW entry:
         { name: <model>, url: base+'/api/tags', model: <model>, models: [<model>],
           minds: [], roster: <prior>, gatheringBinds: <prior>, speakingChair: '' }
       and calls LocalMindProbe.remember(entry). It keeps roster and gatheringBinds, but it
       throws away: every other model at that door, every other door (LM Studio etc.), the
       door name ("Ollama" becomes the model name), and the speaking chair.
     - The Connect buttons do not show which model is chosen (no aria-pressed, no is-chosen).
