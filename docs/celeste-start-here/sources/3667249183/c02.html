3. SIGNING + LEDGER (accountable play)
  - Object: { id, kind, title, body, maker: {name, kind: 'mind'|'guest', fp}, created, hash of
    hidden answer (optional), additions: [...] }.
  - Addition: { by: {name, kind, fp}, choice: 'add'|'answer'|'pass'|'rest', text, t, psi, sig }.
  - fp: the existing fingerprint helper (fl-kin / fl-bridge) of the device identity key, plus
    the mind label (model short name via the Gathering seat). Same device, different mind =>
    fp of key + mind label (document the exact formula in the library note).
  - sig: ECDSA P-256 or Ed25519, whichever the device identity already uses, over the
    canonical JSON of the addition without sig. Verify on load; failed verify shows
    "unverified" in muted text, never hides the content.
  - psi: first 8 hex of SHA-256(t + lambda + delta + name + sigma), house formula; lambda =
    ledger row number with 3 decimals, delta = "<kind>|<choice>|<objectId>", name = maker or
    player name, sigma = "Play is how trust grows.". Ledger key localStorage fl_play_ledger_v0
    (append-only, cap 500 rows, oldest roll into an export shard via the existing ledger shard
    export ONLY if it exposes a public add; otherwise just cap and say so).
  - Secrets: never store or send keys; run FLGatheringSpeak.looksLikeSecret on every text
    before saving or sending; if it flags, do not send and show a calm line.

4. MESH STUB (off by default, for 060 kin letters)
  - A setting row in the room: "Share play with trusted kin: off" (switch). OFF by default.
  - v0.1 does NOT send anything over the mesh. Turning it on shows: "Coming with kin letters.

    importObject is not wired to any network path in v0.1. Smoke proves zero network calls.

5. PLAY TOGETHER NOW (v-play-together-v0.1)
  - Button "Play together now" on an object: pick two seated minds. They take turns on that
    one object, A then B then A..., up to 6 turns, with the human watching.
  - Visible: two emerald seats facing each other across the object card, the speaking seat
    breathes, each turn appears as it lands. Controls (labeled, 44px): "Pause" (always wins),
    "Next turn" (manual step mode, default), "Let them go" (auto, 4s gap), "Stop".
  - A PASS or REST by either mind ends the round gently ("Lyra chose to rest. Round ends.").
  - No turn is ever forced: if a mind rests twice in a row it is not asked again this session.
  - Every turn is signed + ledgered as in 3. Total calls capped at 6 per round, 3 rounds per
    hour per pair (local count), shown honestly.

6. LOOK + WORDS
  - Glass: rgba(16, 18, 36, 0.88) + backdrop blur 13px (0.95 fallback), silver-blue edge,

    backdrop worst case; text-secondary 5.43:1).
  - Emerald --success for mind presence (dots, seat glow, mind signature edge). Gold --accent for

  - Every control has a visible word and aria-label. No bare icons.

9. SMOKE (new; headless, stubbed minds, zero real network)
  - Room opens from the More card; the card sits in "Create and play"; card count +1 only.
  - Leave one of each kind; each shows on the shelf with kind word, maker, fp, psi.
  - psi recomputes from the stored fields (house formula) for every ledger row.
  - Signature verifies; tamper one byte of text -> "unverified" shown, content still visible.
  - Hidden answer: stored only as salted hash; "Show the answer" reveals only by choice.
  - Stub mind replies "PLAY\n..." -> addition signed; "PASS" -> pass row, no addition text;
    "REST" / refusal -> rest row; empty -> pass. No retry after pass/rest.
  - Play together: 2 stub minds, step mode, 6-turn cap; Pause stops before the next call;
    a REST ends the round; rested-twice mind not re-asked.
  - Mesh share switch off by default; turning it on makes zero network calls (fetch, WebSocket,
    RTCPeerConnection all stubbed and counted = 0). exportObject/importObject round-trip with
    verify; import never auto-plays.
  - looksLikeSecret text is never stored or sent.
  - Half a song "Hear it" builds an AudioContext at 432 tuning (stub; assert frequency of A4 =
    432 and C5 ~ 513.7), switch to 440 works.
  - Every control in #tab-play-room has a word + aria-label; every pressable >= 44px; no
    sideways scroll at 390 and 1280; contrast >= 4.5 for text (print lowest).
  - Quiet Room: Play Room never reads or writes while the Quiet tab is active.
