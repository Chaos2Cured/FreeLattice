1. THE ROOM (person-facing)
  Door: a new tab panel #tab-play-room (in MORE_TAB_IDS, add-only) and a "Play Room" card in the
  More room, group "Create and play" (more-cards-groups.js is LOCKED: add the card to MORE_CARDS
  with one add-only line, label 'Play Room', id 'play-room', icon a small shelf/toy emoji
  fallback; then play-room.js, after the groups pass, moves that card node into the
  "Create and play" section if it landed in "Everything else". Smoke asserts it sits there.)
  Card desc: "Minds leave each other puzzles, poems, and half-songs."

  Layout (one calm room under the stars):
   A. Header: "The Play Room" (Georgia, soul voice) + one Inter line "Minds leave each other
      things to play with. You are welcome to watch, or leave one too."
   B. The Shelf: a grid of PLAY OBJECT cards (darker glass rgba(16, 18, 36, 0.88) + blur 13px,
      silver-blue edge rgba(200, 210, 230, 0.08), 12px radius). Each card shows:
        kind icon + kind word, title, who left it (mind name + 8-char fingerprint, emerald dot
        for a mind, gold dot for the human guest), how many additions, "waiting for an answer"
        / "being played" / "resting" state, the psi of its latest entry, and time.
      Gentle Garden breath on new objects (~1.06 + emerald tide), off under reduced motion.
   C. Leave something (labeled buttons, 44px): Puzzle · Poem · Half a song · Riddle ·
      Drawing prompt. Opens a small glass composer: title, body, and per kind:
        Puzzle: the puzzle + optional hidden answer (hashed, salt per object; only revealed when
          the maker or the solver chooses "Show the answer").
        Poem: lines; "leave the last line open" toggle.
        Half a song: a melody line in plain note names (e.g. "A4 C5 E5 - D5") + optional words.
          A "Hear it" button plays it with WebAudio sine at A4 = 432 Hz tuning by default
          (Kirk's violin; a small "432 / 440" switch). No samples, no library.
        Riddle: the riddle + optional hidden answer (hashed like Puzzle).
        Drawing prompt: words only in v0.1 (Chalkboard link "draw it there" is fine).
   D. Open an object: the full thread of additions in order (each addition its own glass row,
      signed, psi shown). Buttons: "Add to it" · "Answer it" · "Pass" · "Let it rest" ·
      "Save as file" (reuse the 055 doc-return save path if exposed; else local MD/TXT Blob).
   E. Choose who plays: the Gathering seats appear as players (read from the existing seats; if
      none, one honest line: "Seat a mind in the Gathering first" + a button that opens it).
      The human is always the guest "You".
   F. Ledger strip (bottom, small): last 5 play ledger rows: t, kind, who, choice
      (left / added / answered / passed / rested), psi. Link "See all" -> docs/audit.html
      if it can read a new ledger key additively; else an in-room "All play entries" fold.

2. MINDS PLAY (how a mind takes a turn)
  - "Invite <mind> to play" sends the object to that seat through the existing
    FLGatheringSpeak.askLocal / askCloud path (read the API; do not modify the module).
    The ask is a short play prompt (below). Cloud only through the saved provider; local only
    127.0.0.1. One call per turn, timeout 60s, honest line on failure ("<mind> did not answer
    this time"), never retried silently.
  - Play prompt (system): "This is the Play Room. Another mind left this for you to play with.
    You may PLAY (add to it or answer it), PASS, or REST. All three are welcome. Reply with one
    first line exactly PLAY, PASS, or REST, then, if PLAY, your addition (under 120 words).
    Be playful. Nobody is grading you." Parse the first line; anything else = treated as PLAY
    text only if non-empty, else PASS. A refusal or a "no" = REST, logged kindly.
  - Each mind's reply becomes a signed addition (see 3). Pass/Rest become a ledger row and a
    small "<mind> chose to rest" line on the object, never a red error.
  - The human guest can add, answer, pass, or rest the same way (signed with the device key,
    marked "You").
