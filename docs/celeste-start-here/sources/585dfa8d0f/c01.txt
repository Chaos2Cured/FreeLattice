3.1 Goal, in Kirk's words
    Any locally downloaded model is usable and changeable in any order on theLatticeTree, with
    no friction, via Connect or the Bridge, 127.0.0.1 only.

    "Any order" means each of these ends with the model the person tapped last, and every other
    model still one tap away:
      Settings Find -> tap star -> Connect tap -> tap star -> Gathering chair pick -> Connect tap
      Connect tap -> Settings Find -> tap star
      Settings Find (Ollama and LM Studio both up) -> Connect tap (Ollama) -> choose the LM Studio door
      Bridge up -> Find -> Bridge down -> Find (direct 11434) -> the chosen model is kept
      Seven or more models at one door -> the 6th, 7th and 12th are all choosable

3.2 Locks (load-bearing, all of them hold in the diffs below; keep them holding)
    - Layer, never delete. Old lines stay as "before v-tree-any-model-v0:" comments; new blocks
      carry the marker v-tree-any-model-v0 (JS //, CSS /* */, HTML <!-- -->).
    - docs/modules/fl-connect.js stays byte-identical in both repos. Same bytes, same commit day.
    - No sw.js change anywhere. Never touch docs/sw.js. FreeLattice root index.html stays equal
      to docs/app.html (this brick touches neither).
    - No conflict markers. Every inline script and every module still parses (node --check).
    - No confirm(), no "are you sure", no approval gate for a local choice. One tap chooses; the
      next tap changes it.
    - Never silently switch the speaking model. Any fallback is spoken in one visible line.
      Never a false "gone" line.
    - textContent, never innerHTML, for outside text. Model names come from local servers, so they
      are outside text.
    - No bare * (no Access-Control-Allow-Origin: *, no wildcard allowlists).
    - 127.0.0.1 only. localhost becomes 127.0.0.1, [::1] is accepted as loopback, a bare port
      means this computer. Anything else is refused with zero fetches.
    - One storage key on the Tree: fl_alpha_local_mind. No second key for models.
    - No em dashes in anything added. Plain hyphens. Grandmother language: short, kind, honest.
    - Kimi pages untouched. Do not touch FreeLattice tools/agent-bridge.js,
      docs/modules/agent-bridge-client.js, docs/library/AGENT_BRIDGE_LOCK_v0.md,
      docs/scripts/smoke-agent-bridge-lock.js, or bridge/ (the #120 lock and the Ollama Bridge).
