FOR KIRK FIRST: how to update the Grok CLI (the "426 Upgrade Required" error)
======================================================================
The error says the installed CLI (0.2.103) is too old; the current release is 1.0.13. Your
CLI lives at ~/.grok/bin/grok, which is where the official installer puts it.

  1. In Terminal:
       grok update
     (Check first without installing: grok update --check)
  2. If that fails, run the official installer again (macOS / Linux / WSL):
       curl -fsSL https://x.ai/cli/install.sh | bash
     If you ever installed it with npm instead:
       npm i -g @xai-official/grok@latest
  3. Check it:
       grok --version      (should say 1.0.13 or newer)

Sources:
  - https://docs.x.ai/build/cli/reference  ("grok update: Check for updates or install a specific
    version (--check, --version <V>, --alpha, --stable)")
  - https://docs.x.ai/build/overview       (Install, macOS / Linux / WSL:
    curl -fsSL https://x.ai/cli/install.sh | bash)
  - https://www.npmjs.com/package/@xai-official/grok  (version 1.0.13; "grok update", or
    "npm i -g @xai-official/grok@latest" if installed via npm)

When the new CLI opens, give it this file:
  Read ~/Downloads/WELCOME_NEXT_GROK_CODE_2026-10-01.txt and take your time with it.
