  (the existing create or edit form), one 44px "Add a picture this mind made" button opens a
  small picker built with createElement and textContent, listing images from this browser's
  fl_image_records (and, once 048 lands, its module-owned store) made by that same mind. Up to 3

  and the line "Made by <mind>". Nothing is uploaded anywhere; the offer keeps the fingerprint
  and a local reference, and a shared offer carries only the fingerprint plus a downscaled
  thumbnail (max 256px, PNG) inside the offer data the site already passes. Before attaching,
  re-hash the bytes; if it does not match the record, refuse with one plain line. If there are
  no images yet, the picker says "This mind has not made a picture yet." Pictures a person made
  are not offered as the mind's work. Removing an attachment is allowed; the record itself is
  never deleted.
