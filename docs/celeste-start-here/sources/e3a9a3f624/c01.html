## Key prescriptions Kimi gave that later shaped Round 2 / exact-match
(Attributed; see t1109u for full wording.)
1. Tiny static Shakespeare loss is not a retention assay ("thermometer to a memory exam").
2. Hashing for addressing (not optimizing) is a legitimate direction; separate three "phi" brands.
3. Test 1 (phi positions) needs verification — suspiciously near-no-op; possible frequency-range bug.
4. Early-advantage claims overclaimed (n=3, multiple comparisons).
5. Killer probes: needle-in-training; associative recall beyond context; continual splits.
6. Four arms + **collision-free oracle** to split collisions vs read path.
7. Oracle parent before learned parent.
8. Rest = consolidation (replay / EMA / slow copy), not low LR.
9. Surprise-gated write-once; fix read path first.
10. Framing line: separate substrate of knowledge from dynamics of learning; measure retention per joule.
