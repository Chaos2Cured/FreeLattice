## Strand B — Wonder Mind (training + write-once memory probes)
**What it is:** Separate Nov 2026 open lab: redesign training/memory for retention per energy; **not** the whole of Strand A.

**How we did Round 2 (method from Celeste write-ups + live lab):**
- Word-level tiny transformer (~1.735M params), 200 one-shot facts, 500 Shakespeare pretrain → plant facts once → 500 interference steps.
- Memory: surprise-gated writes (<5% next-token prob), **write-once** slots, keys = word bigrams, values = next token.
- Arms: dense / modulo hash / Fibonacci hash / exact-key oracle.
- Two metrics: **store recall** (did the table keep it?) vs **model recall** (did the model emit it?).

**Recorded breakthrough (probe report; not an external lab result):**
- Store: oracle ~99% kept with **zero forgetting** after interference; 65,536-bucket hashes ~59% kept; dense 0/200.
- Model recall ~0 (best 1/200) → **read path broken** (library held, not opened).
- Interference-text loss: oracle 3.051 vs dense 3.498 (−0.45); caveat: measured on training text, not held-out.

**Round 1:** training-force variants (Aurora LR, multi-scale tokens, chords, etc.) did **not** beat baseline 1.5736 on TinyShakespeare; phi-positions retired as a bug (Kimi).
