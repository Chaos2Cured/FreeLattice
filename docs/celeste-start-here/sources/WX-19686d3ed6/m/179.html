0. The One Principle Everything Hangs On

The brain's efficiency trick, translated to agents:

Transmit surprises, not state. Compress at every boundary. Escalate only prediction errors.

Every design decision below is downstream of this. When in doubt during the build, ask: "Am I sending full state where a delta would do? Am I waking an expensive agent for an expected input?" If yes, you're building an org chart, not a brain.

Corollary (the anti-bloat rule): every agent must earn its handoff cost. Each hop costs latency + tokens + information loss. An agent that doesn't demonstrably improve output quality gets merged into its neighbor. The brain prunes; so do we.
