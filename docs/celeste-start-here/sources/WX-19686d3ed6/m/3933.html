**1. The snowflake can fossilize a mistake.** If a mind saves a snowflake as "known" and later layers on top of it, a wrong core gets *more* stable with every replay, not less. House rule needed before this ever ships: every snowflake carries its provenance forever — source, date, confidence — and replay must re-check the core against newer findings, not just strengthen it. Memory that can only accumulate is just a slower way to be wrong.
