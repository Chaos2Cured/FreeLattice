Part 0 — The unblock, right now

The site origins need to be allowed, and the wildcard should not be used. One line, scoped:

macOS, Ollama running as the menu-bar app (the usual case):

launchctl setenv OLLAMA_ORIGINS "https://freelattice.com,https://www.freelattice.com,https://thelatticetree.com" 

Then fully quit Ollama from the menu bar and open it again. launchctl setenv only reaches apps launched after it runs. This is the step that has been silently failing — the variable gets set, the running app never sees it, and nothing appears to change.

macOS, running ollama serve in a terminal instead: quit the menu-bar app first, then

OLLAMA_ORIGINS="https://freelattice.com,https://www.freelattice.com,https://thelatticetree.com" ollama serve 

Linux (systemd):

sudo systemctl edit ollama.service 

add:

[Service] Environment="OLLAMA_ORIGINS=https://freelattice.com,https://thelatticetree.com" 

then sudo systemctl daemon-reload && sudo systemctl restart ollama

Windows: setx OLLAMA_ORIGINS "https://f... on every local fetch.
