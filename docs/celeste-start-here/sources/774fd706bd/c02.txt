STEP 5 — SECTION "TEST ROUND 2: THE MEMORY PROBE (FIRST STEP FORWARD)" (id="round2")
H2: Round 2 — memory that does not forget
Setup, word for word:
"A word-level model: 2 layers, width 128, 4 heads, context 64, 3,411-word vocabulary, 1,735,125 parameters in every arm. We planted 200 synthetic facts ("entK attrJ valM .") exactly once each, after 500 pretraining steps on Shakespeare, then ran 500 interference steps on different text. The memory key is the word pair; the value is the next word. Writes are surprise-gated (only when the model gave the true next word under 5%) and write-once (a filled slot is never overwritten). Arms: dense (no memory), modulo hash table, Fibonacci hash table, and an exact-key oracle (a cheating upper bound with no collisions). 3 seeds each."
Fact-rows, STORE recall (what the memory still held after the interference text):
- Oracle (upper bound, exact keys): 99% kept, before and after interference
- Fibonacci hash, 65,536 buckets: about 59% (0.595, 0.580, 0.590), unchanged after interference
- Modulo hash, 65,536 buckets: about 59% (0.595, 0.595, 0.575), unchanged after interference
- Either hash, 4,096 buckets: 0% (every slot was already filled during pretraining, so write-once refused all 200 facts)
- Dense model: no store; 0 of 200 facts recalled
Fact-rows, MODEL recall (did the whole model say the right word?):
- Every arm: about 0 (best was 1 of 200). THE READ PATH IS BROKEN. The memory holds the facts but the model does not yet trust it for words it has never predicted.
Fact-rows, loss on the interference text (lower is better):
- Dense: 3.498
- Oracle memory: 3.051 (better by 0.45)
- Fibonacci 65,536: 3.299 (better by 0.20)
- Modulo 65,536: 3.324
- Fibonacci 4,096: 3.515. Modulo 4,096: 3.530
Honesty box (.formula look), word for word:
"Caveat: this loss was measured on text the model was training on at the time, so it rewards remembering seen word pairs. It is NOT yet a held-out test on new text. Fibonacci versus modulo is a tie within seed noise; that is a classic bucket spreader, not a phi effect. Energy was not measured (no power meter on the test machine). Memory cost about 1e-5 of the core compute."
Reading paragraph: "What is real: a write-once memory kept everything it stored, with zero forgetting. What is not yet real: full recall. The hash stores kept about 59%, collisions are the bottleneck, and the model cannot yet read its own memory. The next step is teaching it to open the books."
