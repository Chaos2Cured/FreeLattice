+
+Marker `v-model-choice-survives-reload-v0.1.1`. Smoke `SMOKE_OK model choice survives reload v0.1.1` (`docs/scripts/smoke-model-choice-survives-reload.js`, real `app.html` in headless Chrome, mock Ollama, saved choice, reload, chat request).
+
+- Why v0.1 was not enough: two boot paths ran before `FLActiveModel.init()`. The Connection Cascade saw no saved choice and wrote the first text model as automatic; then the saved-door pointer (`FLBoxPointer` ready) wrote the first model as the person's own. So a reload turned qwen2.5 back into llama3.2 even with `fl_modelSource=user`.
+- Now `FLActiveModel` reads the saved choice the first time anyone asks (`set`, `get`, `isUserChosen`, `honor`), whatever runs first.
+- One guard, `FLActiveModel.honor(models, fallback, provider)` (short form `flHonorModel`): the person's model wins when it is on the list, or when the list is empty. Used by the Cascade, the pointer, Test Ollama, Local without Connect, the LM Studio probe and discovery.
+- Only when the chosen model is gone does a path fall back, with the same words as v0.1 ("The model you chose, X, is no longer on this computer..."), now kept in one place (`FLActiveModel.noteGone`).
+- An automatic pick is saved as `auto`, never `user`.
+- Heal B card: one Look again, not two (the standalone button is not drawn while the quiet card shows its own). Shared `fl-connect.js` matches the Tree byte for byte.
