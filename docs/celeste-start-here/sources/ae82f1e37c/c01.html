  a. Accept these openings, case-insensitive, for the notebook: "[FL_WS:", "[FL WS:", "[FL-WS:",

     spaces before the colon ("[FL_WS :"). Same rule for clay: "[FL_CLAY:", "[FL CLAY:",
     "[FL-CLAY:", "[fl_clay:". A regex like /\[\s*fl[\s_-]?ws\s*:/i (and fl[\s_-]?clay) finds the
     opening; everything after it stays exactly as today.
  b. Still JSON.parse only (no eval, no new Function, no loose object parsing). Keep the
     balanced-bracket scan, the 8 KB / 2048-char caps, the key allowlists and op allowlist.
