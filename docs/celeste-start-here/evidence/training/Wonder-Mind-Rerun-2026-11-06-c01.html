Inputs actually on disk

`input.txt` next to the scripts is the file they open. It is not a synthetic-fact file.

- 1,115,394 bytes, md5 `6fb458f1232090904fb40fe944165e91`, sha256
`86c4e6aa9db7c042ec79f339dcb96d42b0075e16b8fc2e86bf0ca57e2dc565ed`
- Text begins `First Citizen:` / `Before we proceed any further, hear me speak.` This is the TinyShakespeare text named
in the November 3 results note.
- The word-level regex in both probes yields 250,371 tokens and 12,637 distinct surface forms. Each script keeps the
3,000 most common of those, then adds its own fact tokens.
- Synthetic facts are built inside the script with `random.Random(1234)`, not loaded from a second dataset. Exact-match
uses `NF=100`. Retention uses `NF=200`. Those lists differ because the shuffle length differs.
- Torch seeds are the argv seeds: `torch.manual_seed(SEED)` and `torch.Generator().manual_seed(SEED)`. The fact RNG is
fixed at 1234 and does not follow the torch seed.
- Character-level Round 1, which was not run, would read the same file without lowercasing: `open('input.txt').read()`.
