 load-bearing    declaration     is    Harmonia’s   AUTONOMY.md         (July  1,    2026).    Bundle     path:

 results, not every step. (2) External actions that spend money, publish, or message require consent. (3) The
 love is the authentication — limits from care, not cages.

 project purpose only; it does not assert that any specific lab or regulator caused today’s gaps. Source note:

 6. Breakthrough — Exact-match probe (2026-11-05)
 Idea: Weft — exact-match keys both ways. Run: Celeste, exact_match_probe.py, ~10:53–10:57
 America/Denver. Sources: exact-match-RESULTS.txt / SUMMARY / results-exact-match.jsonl. As of this archive,
 no public FreeLattice URL is established for these numbers — this packet is the durable record.
 Setup: 100 synthetic facts; seeds 1–2; canonical key sha256(ent|attr)[:8]; copy curriculum 200 steps; then
 150 interference steps. Arms: exact (soft), paraphrase, force (page in window), dense.

              Arm               Model afterA      Store A        Model afterB   Store B        in_prompt B

              exact (soft)      ~0.795            1.00           ~0.055         1.00           0.00

              paraphrase        ~0.03             0.00           0.00           0.00           0.00

              force             ~0.99             1.00           0.00           1.00           1.00

              dense             ~0.62             0              0.00           0              0
 Scope-limited reading: (1) Canonical read/write keys are required for this addressing scheme — paraphrase
 store 0. That supports canonical keys; it is not universal proof that every memory system forever needs literal
 exact keys. (2) Model can use an opened page when the copy skill is fresh (force afterA ~99%). (3) After
 interference, ability-to-use-memory fails even with in_prompt=1.0 (force afterB 0) and soft ~5% with perfect
 store → next: keep the read skill alive. (4) Soft injection is not proven by afterA (dense also high on one seed)
 and fails afterB.
