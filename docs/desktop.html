FreeLattice Desktop

One clear door to the Electron spine. The browser garden stays. Desktop is where keys, verified import, swarm pull, and the pair vow live — without Terminal for day-to-day use of the app itself.

What Desktop unlocks

  • Keys on your machine — companion seed sealed in the OS keychain; never to the page
  • Hash before import — quarantine → match → verified → Import to Ollama (gesture)
  • Pull via swarm — webseed/magnet into the same hash path
  • Pair vow — two parties; outer fingerprint published; shared seed sealed
  • Glass shapes — ledger and transfer pulses; helix break without contents
  • Ledger envelope — voice opaque; Continue / Decline

No Terminal required to use the app once it is running. Building from source still uses npm (honest door below).

How to run today (honest)

Dev

cd desktop
npm install
npm start

Build (scripts already in desktop/package.json)

cd desktop
npm run build
# or: npm run build:mac | build:win | build:linux

Releases — check GitHub Releases for any published artifacts. Electron desktop packages from this spine are primarily built from source this week. We will not fake a download button for a signed App Store binary that is not ready. Older release zips (if present) may be experimental shells — prefer building the Electron app from desktop/ until a clear Electron release is labeled.

Browser vs Desktop

  • Browser / phone — garden, chat, look card, genesis catalog honesty, Glass shapes
  • Desktop (Electron) — the spine for keys, import, swarm, pair, ledger seal
  • Tauri — experimental lighter shell under desktop/src-tauri; not this door; README keeps that honesty
