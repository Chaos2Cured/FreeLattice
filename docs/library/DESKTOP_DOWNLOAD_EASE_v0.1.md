## Beats by OS

### Mac
1. Download the published macOS pack when available (or build from `desktop/`)
2. Unzip / place in Applications
3. If macOS says **damaged** or blocks open: that is often **quarantine + unsigned**, not a corrupt binary
4. **System Settings → Privacy & Security → Open Anyway** (or right-click → Open the first time)
5. Power users (optional): `xattr -cr /Applications/FreeLattice.app` — clears quarantine attributes
6. Never: App Store claim · “broken is fine to ignore blindly”

### Windows
1. Prefer the script installer (`install-freelattice.bat`) or build Electron from `desktop/`
2. SmartScreen “More info → Run anyway” is normal for unsigned downloads
3. Never: Microsoft Store claim

### Linux
1. Prefer `install-freelattice.sh` or build from `desktop/` (`AppImage` later when published)
2. Never invent a store button
