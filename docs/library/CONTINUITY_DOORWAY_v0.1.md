# Continuity doorway note v0.1

One calm line of last intent on FreeLattice. It sits under the tab row. It names a short ask from Chat, a Gathering ask, a Connect door the person used, or Apply on a local build. Continue returns to that place. It does not send a new message and it does not invent an answer.

The note lives on this device under `fl_continuity_doorway_v0`. It keeps short text, a place, and a time. It never keeps a key. A key-shaped note is refused. Older than seven days, it stays quiet. Nothing recent stays quiet. There is no first-open nag.

Pause hides the line. Pause during a Gathering turn drops a Gathering note so the line does not pretend that turn is still going. A new Chat conversation, and Clear Memory, drop the note this brick owns.

`fl-connect.js` is not edited. `ai-continuity.js` is not edited. That file is the relationship shape. This note is the person's doorway.

The Tree has a Chat word that opens a different room, and a galaxies menu. It does not have this Chat tab and More shell. No second face was added there. The speaking chair is still not mounted on a Tree page.
