# Honest boxes, Sol's snowflake notes, and check before commit v0.1

Truth is more efficient than deceit. 'I don't know' is a complete, honest answer.

Kirk asked for the device-only controls to look like the rest of the site, and for a way to hide them. The keep switch uses the same glass, border, and radius as the secondary buttons. Padding lives in the stylesheet, and the tap stays at least 44px. `fl_honestBoxesHidden` remembers a hide. Showing the controls again does not change `keepOn` for any chat. The same hide line sits beside the settings note, with the check-before switch.

Sol named three gaps in Snowflake. A node used to keep only the first result's title and snippet. A conclusion was asked with a node count, so the mind never saw what it was concluding about. The line "this became part of me" was said before any adapter was trained.

A page is fetched only when a real page route is offered: a `/page` search path, an `offersPage` sibling of `/search`, `FLWebTool.getPageEndpoint`, or `FLWebTool.fetchPage`. Otherwise the node stays a snippet, and the fetch is not spent. Readable text is capped at 6000 characters. The page sha256 and the fetched time are stored. A failed fetch keeps the snippet and says `depth` is `snippet`.

The first result stays the main source, so an older signature still verifies. Up to three sources are stored. They enter the signature only when `sigV` is 2. The card says how many sources it has.

The conclude ask and the grow ask each send, per node, the id, the branch, the confidence, a 280-character summary, and the source count. The dissenter's words go with them. The raw question does not. The whole ask stays within 4000 characters.

Growth says what is true. With a trainer on the device, the line is "Chosen for growth; training queued." With no trainer, it says so. "This became part of me" is said only when an adapter is trained, loaded, and checked.

`fl_checkBeforeCommit` defaults on. After the grow choice, and before anything is written to growth or memory, one preview shows the chosen summaries with Keep, Change, and Skip. Skip writes no growth row. The flake is already saved. Change drops the last chosen id and leaves the preview open. When the switch is off, there is no preview, and the growth row is written as before. The preview does not open when the Quiet Room is shut.
