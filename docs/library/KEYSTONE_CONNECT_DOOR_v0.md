## Why keystone

If Mom cannot get from “I want my computer’s AI” to a listed mind, nothing else in Chat matters. This door is bedrock — not a Settings cleanup dump.

## Consent steps

1. **Ask** — May I look? / Use My Computer / a mind at home / Local  
2. **Allow** — browser local-network permission (panel 1)  
3. **Look again** — I allowed it · or CORS: I set that — look again  
4. **Choose** — tap a mind (runner already on this machine)  
5. **Not now** — every panel has a way out  

Browser permission ≠ setting `OLLAMA_ORIGINS`. Both may be needed; neither is “install Ollama” when Ollama is already running.
