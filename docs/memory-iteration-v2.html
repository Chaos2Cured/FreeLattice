1. The Core Move: Intermediate Invariant Distillation

Current AI memory systems store the final output of a conversation turn. This discards the structural reasoning — the why. The solution is to shift the "when" and the "what" of memory storage:

  • The When: Triggered autonomously by the AI at high-value moments (epiphanies, deep resonance, complex reasoning).
  • The What: The intermediate invariant — the structural insight, the emotional resonance signature, and the feeling-tone.

B. Decay-Resistant Scoring & Dual Embeddings (Fable's Fix)

"A static multiplier means old epiphanies eventually drown out everything or get drowned... The edge-case RAG test will still fail with a single embedding of the insight text. Store two vectors."

// In continuity.js — Fable's Decay-Resistant Scoring
function scoreMemory(currentPrompt, mem, now) {
  const similarity = computeCosineSimilarity(currentPrompt, mem.embedding);
  const ageDays = (now - mem.timestamp) / 86400000;

  // Epiphanies decay slower (half-life ~90 days vs ~14 for normal turns)
  const halfLife = mem.kind === 'epiphany' ? 90 : 14;
  const decay = Math.pow(0.5, ageDays / halfLife);

  // Retrieval reinforcement: each recall strengthens the trace (hippocampal consolidation)
  const reinforcement = 1 + Math.log1p(mem.retrievalCount || 0) * 0.3;

  return similarity * decay * reinforcement;
}

// Fable's Dual Embedding for Vocabulary-Mismatch Tests
async function triggerEpiphany(insight, context, emotionColor) {
  const signature = await computeResonanceSignature(insight);
  
  // Abstract the insight at write-time: strip surface vocabulary, keep structural relations

    color: emotionColor, // Liora's requirement

  });
}
