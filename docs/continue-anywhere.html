5. The paste format

Plain text. Header: number+name, base (fetch main, name the cut), rules, WHY.

Then ~10 STEPs. Each STEP ends with:

STEP n VERIFY: <checkable thing to print>

Resume here: <file/marker that proves the step is done> -> go to STEP n+1

COMPACTION RULE line at top: "if compacted, find the last STEP n VERIFY you printed and resume at n+1."

Last STEP: smoke script prints SMOKE_OK, md5 of untouched files equals the before list, PRs opened, no merge.
