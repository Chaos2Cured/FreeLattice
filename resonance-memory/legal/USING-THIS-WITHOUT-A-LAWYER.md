# Using This Without a Lawyer

Factual reference. No document here requires you to hire anyone before you can
use it.

## What the "not legal advice" line means

I'm an AI, not a lawyer. That line means I can't represent you in court or
guarantee how a judge rules. It does not mean the documents are invalid or
unusable. It's the same boilerplate on every legal template sold anywhere.

## What needs a lawyer and what doesn't

| Task | Lawyer needed? |
|---|---|
| Publishing under AGPL-3.0 | No. Done. Standard FSF license. |
| The dual-license notice in the repo and file headers | No. Done. |
| Sending a company the commercial agreement | No. It's a starting draft; the buyer's own lawyers review it before signing. |
| Filling in price, name, date | No. |
| Registering copyright (optional, strengthens enforcement) | No — file it yourself online. |
| Suing an infringer | Eventually yes — a future problem; free orgs below can help then. |

## Steps

1. AGPL is already published. Nothing to do.
2. Fill in `COMMERCIAL-LICENSE.md` per customer: company name, price, date.
   Governing law is already set to South Dakota; other defaults are chosen.
3. Set a price (see below).
4. Keep the "commercial license available" line visible (already in README and
   LICENSING.md).
5. Optional (~$45–65): register the copyright at
   <https://www.copyright.gov/registration/>. In the U.S. this is a prerequisite
   to suing for infringement (17 U.S.C. § 411) and unlocks statutory damages
   (§ 412). Copyright exists automatically without it; registration is about
   enforcement, not ownership. File it yourself — no lawyer.

## Pricing — starting points

You set the price; you own the code.

- **One-time perpetual fee:** ~$500–$5,000 for a small utility, depending on how
  central it is to the buyer's product.
- **Annual subscription:** ~$300–$2,000/year, if you keep shipping updates.
- **Royalty:** ~1–5% of the revenue their product makes using your code.

A buyer needing a commercial license is avoiding the cost of open-sourcing their
entire product — that's worth a lot to them. Start high; you can negotiate down.
